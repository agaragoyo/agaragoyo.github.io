# 내 앱 만들기

아가라고요 컴퓨터의 앱은 `apps/` 폴더 안의 웹 페이지 하나입니다. 미니게임도 앱이고, 바탕화면에 올라가는 프로그램도 앱입니다.
아가라고요 코드를 몰라도 HTML 파일 하나만 만들 줄 알면 앱을 붙일 수 있습니다.

## 시작하기

가장 빠른 방법은 예시 앱을 복사하는 것입니다. `apps/tidy-up` 폴더(짐 정리)를 통째로 복사해서 이름을 바꾸고(예: `apps/sand-dig`),
그 안의 `index.html`을 내 게임으로 고칩니다. 이 페이지는 아가라고요 밖에서 브라우저로 혼자 열어도 동작하므로,
만드는 동안에는 그냥 내 페이지를 열어서 확인하면 됩니다.

다 만들었으면 `data/apps.js`의 목록에 한 줄을 추가합니다.

```js
{ id: 'sand-dig', title: '모래 파기', icon: 'apps/sand-dig/icon.png', src: 'apps/sand-dig/index.html', size: [480, 360], folder: 'games' },
```

`size`는 창 안쪽 크기이고, 바탕화면 전체가 1280×800입니다. `folder: 'games'`를 붙이면 미니게임 폴더 안에 들어가고,
빼면 바탕화면에 아이콘이 생깁니다. 아이콘 그림이 없으면 `icon`을 빼고 `color: '#e3cf98'`처럼 색만 적어도 됩니다.
그러면 그 색 타일에 제목 첫 글자가 들어간 아이콘이 만들어집니다.

## 지킬 것

앱은 자기 폴더 안의 파일만 씁니다. 다른 앱 폴더나 `src/` 폴더의 파일은 건드리지 않습니다.
CSS나 전역 변수는 마음대로 써도 됩니다. 앱은 iframe이라는 별도의 창 안에서 돌아가서, 다른 앱이나 방 꾸미기와 섞이지 않습니다.

캔버스, DOM, p5.js 중 무엇을 써도 됩니다. 다만 npm이나 빌드 도구 없이 그대로 열리는 파일로 만들어 주세요.
라이브러리가 필요하면 `<script src="https://cdn.jsdelivr.net/...">`처럼 CDN 주소로 불러옵니다.

최고 점수나 이어 하기를 localStorage에 저장할 때는 키 이름을 내 앱 id와 점으로 시작해 주세요(`tidy-up.best`처럼).
모든 앱이 한 저장소를 같이 쓰기 때문에, 이름이 겹치면 다른 앱의 기록을 덮어씁니다.
로그인 화면의 "이 컴퓨터 초기화"도 이 이름으로 우리 기록을 골라 지웁니다.

## 아가라고요와 주고받기 (선택)

창을 닫거나 방 주인 이름을 알고 싶으면 페이지에서 SDK를 불러옵니다.

```html
<script src="../aga-sdk.js"></script>
```

그러면 `AGA.close()`로 내 창을 닫고, `AGA.setTitle('모래 파기 (최고 12점)')`로 창 제목을 바꿀 수 있습니다.
`AGA.info()`는 방 주인 닉네임과 지금 친구 컴퓨터를 구경하는 중인지를 알려 줍니다.
아가라고요 밖에서 혼자 열었을 때도 오류가 나지 않고 빈 값을 돌려줍니다. 사용 예는 `apps/tidy-up/index.html`에 있습니다.

## 알아 두면 좋은 것

모니터의 볼록 효과가 켜져 있으면 화면이 실제로 휘어 보이고, 아가라고요가 마우스 위치를 고쳐서 앱 안으로 넣어 줍니다.
같은 사이트 안의 앱(`apps/` 폴더)은 이 보정이 정확하게 들어갑니다. 다른 사이트 주소를 `src`에 넣으면 보정이 들어가지 않아서,
창 가장자리 쪽을 누를 때 몇 픽셀 어긋날 수 있습니다.

마우스 이벤트는 `pointerdown`, `pointermove`, `pointerup`, `click`, `mousedown`, `mousemove`, `mouseup`, `wheel`이 들어갑니다.
더블클릭(`dblclick`)과 오른쪽 클릭 메뉴(`contextmenu`)는 아직 들어가지 않으니, 게임 조작에 쓰지 말아 주세요. 키보드는 그대로 들어갑니다.

캔버스로 게임판을 그리고 창 크기에 맞춰 늘리고 줄인다면, `html, body`에 `overflow: hidden`을 주고 크기를 정수로 내려서 맞춰 주세요.
스크롤바가 생겼다 사라졌다 하면서 화면이 떨리는 문제가 생길 수 있습니다(짐 정리에서 실제로 있었습니다).

AI에게 앱을 만들어 달라고 할 때는 이 파일과 `apps/tidy-up/index.html`을 같이 보여 주면 같은 형식으로 만들어 줍니다.
