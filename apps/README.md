# 내 앱 만들기

아가라고요 컴퓨터의 앱은 `apps/` 폴더 안의 웹 페이지 하나입니다. 미니게임도 앱이고, 바탕화면에 올라가는 프로그램이나 가구를 두 번 눌렀을 때 열리는 화면도 앱입니다.
아가라고요 코드를 몰라도 HTML 파일 하나만 만들 줄 알면 앱을 붙일 수 있습니다.

## 시작하기

`apps/_template` 폴더를 통째로 복사해서 내 앱 이름으로 바꾸는 것부터 시작합니다(예: `apps/sand-dig`). 이름은 영어 소문자, 숫자, 하이픈으로 짓습니다.
틀에는 "점을 누르면 점수가 오르는" 아주 작은 게임이 들어 있고, 그리기, 마우스 입력, 최고 점수 저장, 창 닫기가 모두 SDK로 연결되어 있습니다.
필요한 부분만 내 게임으로 바꾸면 됩니다. 이 페이지는 아가라고요 밖에서 혼자 열어도 동작하므로, 만드는 동안에는 내 페이지만 열어서 확인해도 됩니다.

다 만들었으면 `data/apps.js`의 목록에 한 줄을 추가합니다.

```js
{ id: 'sand-dig', title: '모래 파기', icon: 'apps/sand-dig/icon.png', src: 'apps/sand-dig/index.html', size: [480, 360], folder: 'games', group: 'mini' },
```

`id`는 폴더 이름과 같게 씁니다. `size`는 창 안쪽 크기이고, 바탕화면 전체가 1280×800입니다.
`folder: 'games'`를 붙이면 게임 폴더 안에 들어가고, 빼면 바탕화면에 아이콘이 생깁니다. 게임 폴더에 넣을 때는 `group: 'mini'`도 적습니다(작은 게임이 나오는 묶음 "미니게임"이고, 다른 묶음은 `data/apps.js` 맨 위 설명에 있습니다).
아이콘 그림이 없으면 `icon`을 빼고 `color: '#e3cf98'`처럼 색만 적어도 됩니다. 그러면 그 색 타일에 제목 첫 글자가 들어간 아이콘이 만들어집니다.

## 가구에 붙이기

냉장고를 두 번 누르면 요리 게임이 열리는 것처럼, 바탕화면에서 가구를 두 번 눌렀을 때 내 앱이 열리게 할 수 있습니다(아바타가 가구 옆으로 걸어간 뒤 열립니다).
앱을 위와 같이 만들어 목록에 넣고, `folder: 'furniture'`를 붙입니다. 그러면 바탕화면이나 게임 폴더에는 나오지 않고 가구로만 열립니다.
그다음 `data/furniture.js`에서 그 가구 줄에 `gimmick: 'app:<내 앱 id>'`를 더합니다.

```js
// data/apps.js
{ id: 'fridge-cook', title: '냉장고 요리', color: '#9fd8e8', src: 'apps/fridge-cook/index.html', size: [520, 420], folder: 'furniture' },
// data/furniture.js 의 냉장고 줄
{ id: 'fridge', scene: 'room', name: '냉장고', zone: 'floor', size: [1, 1], height: 120, color: '#e9eef2', gimmick: 'app:fridge-cook' },
```

가구 목록에 없는 새 가구라면 줄을 하나 새로 만들면 됩니다. 각 칸의 뜻은 `data/furniture.js` 맨 위에 적혀 있습니다.

## 아가라고요와 주고받기 (SDK)

틀은 이미 SDK를 불러오고 있습니다. 직접 만든 페이지라면 `<script src="../aga-sdk.js"></script>`를 내 스크립트보다 먼저 넣습니다.

- `AGA.fitCanvas(캔버스, 자리, 가로, 세로)`: 게임판을 자리에 꽉 차게 맞춥니다. 그리기는 늘 `가로×세로` 게임 단위로 하면 되고, 돌려받은 `board.point(이벤트)`가 마우스 위치를 게임 단위로 바꿔 줍니다.
- `AGA.save('best', 12)`, `AGA.load('best', 0)`: 이 컴퓨터에 기록을 남기고 읽습니다. 키 앞에 내 앱 id가 저절로 붙어서(`sand-dig.best`) 다른 앱 기록과 섞이지 않고, "이 컴퓨터 초기화"를 누르면 함께 지워집니다.
- `AGA.close()`, `AGA.setTitle('모래 파기 (최고 12점)')`: 내 창을 닫거나 창 제목을 바꿉니다.
- `AGA.info()`: 방 주인 닉네임과 지금 친구 컴퓨터를 구경하는 중인지를 알려 줍니다.
- `AGA.gameCard(캔버스, { title, how, demo })`: 창을 열면 게임판 위에 시작 카드를 띄웁니다. 아래 "시작 카드"에서 설명합니다.
- `AGA.onHide(함수)`, `AGA.onShow(함수)`: 창을 최소화하거나 다시 띄울 때 알려 줍니다. 아래 "창을 최소화했을 때"에서 설명합니다.

## 시작 카드

미니게임은 창을 열자마자 판이 돌기 시작하면, 처음 하는 사람이 무엇을 해야 하는지 모른 채 시간을 잃습니다.
그래서 우리 미니게임은 판 위에 시작 카드를 먼저 띄우고, 시작 단추를 누를 때까지 판과 시계를 멈춥니다.
카드에는 위에서부터 게임 이름, 조작 안내 한 문장, 2~3초마다 되풀이되는 시범 그림, 기록, 시작 단추가 들어갑니다.
틀(`apps/_template`)에 이미 연결되어 있으니 글과 시범 그림만 내 게임에 맞게 바꾸면 됩니다.

```js
const card = AGA.gameCard(cv, {
  title: '모래 파기',
  how: '모래를 눌러 보물을 찾아 보세요.',          // 조작 안내는 "~해 보세요" 한 문장
  demo: { width: 240, height: 100, period: 2600, draw(g, t) { /* t는 0부터 period까지(ms) */ } },
});
card.open({ note: `최고 ${best}점`, rows: [{ buttons: [{ text: '게임 시작', main: true, onClick() {} }] }] });
```

게임 쪽에서는 `card.isOpen`인 동안 움직임과 시계를 멈추기만 하면 됩니다. 판 위의 클릭은 카드가 막아 줍니다.
머리줄에 "게임 방법" 단추를 두고 누르면 같은 카드를 "이어서 하기" 단추로 다시 열어 주시기 바랍니다.
카드는 판보다 커지지 않게 저절로 줄어들어서, 게임기 가구 화면처럼 작은 자리에서 열어도 판 밖으로 넘치지 않습니다.

처음 하는 사람에게 실제 판에서 한 수를 짚어 주려면 `card.tip('눌러서 떨어뜨려 보세요', { at: 0.3, onSkip })`로
판 위에 한 줄 안내와 건너뛰기 단추를 띄웁니다. 안내를 이미 본 사람에게 다시 띄우지 않도록 `AGA.save('tutored', true)`로 남겨 둡니다.
짐 정리(`apps/tidy-up`)와 파일 정리 10(`apps/file-ten`)이 이 방식으로 만들어져 있습니다.

아가라고요 밖에서 혼자 열었을 때도 오류가 나지 않고, 창과 관련된 기능은 조용히 넘어갑니다.

## 창을 최소화했을 때

창을 최소화해도 게임은 보이지 않는 채로 계속 돌아갑니다. 시계가 있는 게임이라면 다른 창을 보는 사이에 시간이 흘러 버립니다.
`AGA.onHide(함수)`와 `AGA.onShow(함수)`로 함수를 넣어 두면, 창이 최소화될 때와 작업 표시줄에서 다시 띄울 때 그 함수가 불립니다.
가려진 동안에는 시작 카드가 떠 있을 때처럼 움직임과 시계를 멈추면 됩니다.

```js
let hidden = false;
AGA.onHide(() => { hidden = true; });
AGA.onShow(() => { hidden = false; });
// 게임 루프 안에서
if (!card.isOpen && !hidden) { /* 움직임과 시계 */ }
```

짐 정리는 다시 띄우면 멈춘 곳에서 바로 이어집니다. 파일 정리 10은 시계가 흐르던 판이면 다시 띄울 때 "이어서 하기" 카드를 띄워서,
작업 표시줄을 누른 손이 판으로 돌아오는 동안 시간을 잃지 않게 합니다.
지금은 실험실의 "최소화하면 게임 멈추기"를 켠 브라우저에만 이 알림이 갑니다.
SDK를 불러오지 않는 앱은 알림을 받지 못하므로, 다른 사이트의 게임은 이 방법으로 멈추게 할 수 없습니다.

## 지킬 것

앱은 자기 폴더 안의 파일만 씁니다. 다른 앱 폴더나 `src/` 폴더의 파일은 건드리지 않습니다.
CSS나 전역 변수는 마음대로 써도 됩니다. 앱은 iframe이라는 별도의 창 안에서 돌아가서, 다른 앱이나 방 꾸미기와 섞이지 않습니다.

캔버스, DOM, p5.js 중 무엇을 써도 됩니다. 다만 npm이나 빌드 도구 없이 그대로 열리는 파일로 만들어 주시기 바랍니다.
라이브러리가 필요하면 `<script src="https://cdn.jsdelivr.net/...">`처럼 CDN 주소로 불러옵니다.

기록은 `AGA.save`로 저장해 주시기 바랍니다. localStorage를 직접 쓴다면 키 이름을 내 앱 id와 점으로 시작해야 합니다(`sand-dig.best`처럼).
모든 앱이 한 저장소를 같이 쓰기 때문에 이름이 겹치면 다른 앱의 기록을 덮어씁니다. 자동 점검(`python tools/check.py`)이 이 규칙을 확인합니다.

## 알아 두면 좋은 것

앱 창 안에는 마우스와 키보드 입력이 브라우저에서 그대로 들어갑니다. 더블클릭과 오른쪽 클릭 메뉴도 그대로 쓸 수 있습니다.

SDK를 불러온 앱은 아가라고요 창 안에서 기본 커서가 그 시절 모양의 화살표로 바뀝니다. 버튼처럼 누를 수 있는 곳에 손가락 커서를 쓰려면
`cursor: pointer` 대신 `cursor: var(--aga-hand, pointer)`라고 적어 주시기 바랍니다. 혼자 열었을 때는 뒤에 적은 `pointer`가 나옵니다.
쥔 손(`--aga-grab`, `--aga-grabbing`)과 모래시계(`--aga-wait`)도 같은 방식으로 쓸 수 있습니다.

`html, body { overflow: hidden }`과 머리줄의 `white-space: nowrap`은 지우지 말아 주시기 바랍니다. 스크롤바가 생겼다 사라지거나 머리줄이 두 줄이 되면서
게임판이 떨리는 문제가 실제로 있었습니다(known-issues 12, 14). `AGA.fitCanvas`를 쓰면 나머지는 SDK가 알아서 막아 줍니다.

AI에게 앱을 만들어 달라고 할 때는 이 파일과 `apps/_template/index.html`을 같이 보여 주면 같은 형식으로 만들어 줍니다.
