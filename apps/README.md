# 내 앱 만들기

아가라고요 컴퓨터의 앱은 `apps/` 폴더 안의 웹 페이지 하나입니다. 미니게임도 앱이고, 바탕화면에 올라가는 프로그램이나 가구를 두 번 눌렀을 때 열리는 화면도 앱입니다.
아가라고요 코드를 몰라도 HTML 파일 하나만 만들 줄 알면 앱을 붙일 수 있습니다.

## 시작하기

`apps/_template` 폴더를 통째로 복사해서 내 앱 이름으로 바꾸는 것부터 시작합니다(예: `apps/sand-dig`). 이름은 영어 소문자, 숫자, 하이픈으로 짓습니다.
틀에는 "점을 누르면 점수가 오르는" 아주 작은 게임이 들어 있고, 그리기, 마우스 입력, 최고 점수 저장, 창 닫기가 모두 SDK로 연결되어 있습니다.
필요한 부분만 내 게임으로 바꾸면 됩니다. 이 페이지는 아가라고요 밖에서 혼자 열어도 동작하므로, 만드는 동안에는 내 페이지만 열어서 확인해도 됩니다.

다 만들었으면 `data/apps.js`의 목록에 한 줄을 추가합니다.

```js
{ id: 'sand-dig', title: '모래 파기', icon: 'apps/sand-dig/icon.png', src: 'apps/sand-dig/index.html', size: [480, 360], folder: 'games' },
```

`id`는 폴더 이름과 같게 씁니다. `size`는 창 안쪽 크기이고, 바탕화면 전체가 1280×800입니다.
`folder: 'games'`를 붙이면 미니게임 폴더 안에 들어가고, 빼면 바탕화면에 아이콘이 생깁니다.
아이콘 그림이 없으면 `icon`을 빼고 `color: '#e3cf98'`처럼 색만 적어도 됩니다. 그러면 그 색 타일에 제목 첫 글자가 들어간 아이콘이 만들어집니다.

## 가구에 붙이기

냉장고를 두 번 누르면 요리 게임이 열리는 것처럼, 바탕화면에서 가구를 두 번 눌렀을 때 내 앱이 열리게 할 수 있습니다(아바타가 가구 옆으로 걸어간 뒤 열립니다).
앱을 위와 같이 만들어 목록에 넣고, `folder: 'furniture'`를 붙입니다. 그러면 바탕화면이나 미니게임 폴더에는 나오지 않고 가구로만 열립니다.
그다음 `data/furniture.js`에서 그 가구 줄에 `gimmick: 'app:<내 앱 id>'`를 더합니다.

```js
// data/apps.js
{ id: 'fridge-cook', title: '냉장고 요리', color: '#9fd8e8', src: 'apps/fridge-cook/index.html', size: [520, 420], folder: 'furniture' },
// data/furniture.js 의 냉장고 줄
{ id: 'fridge', scene: 'room', name: '냉장고', zone: 'floor', size: [1, 1], height: 120, color: '#e9eef2', gimmick: 'app:fridge-cook' },
```

가구 목록에 없는 새 가구라면 줄을 하나 새로 만들면 됩니다. 각 칸의 뜻은 `data/furniture.js` 맨 위에 적혀 있습니다.

## 아가라고요와 주고받기 (SDK)

틀은 이미 SDK를 불러오고 있습니다. 직접 만든 페이지라면 `<script src="../aga-sdk.js"></script>`를 내 스크립트보다 먼저 넣습니다.

- `AGA.fitCanvas(캔버스, 자리, 가로, 세로)`: 게임판을 자리에 꽉 차게 맞춥니다. 그리기는 늘 `가로×세로` 게임 단위로 하면 되고, 돌려받은 `board.point(이벤트)`가 마우스 위치를 게임 단위로 바꿔 줍니다.
- `AGA.save('best', 12)`, `AGA.load('best', 0)`: 이 컴퓨터에 기록을 남기고 읽습니다. 키 앞에 내 앱 id가 저절로 붙어서(`sand-dig.best`) 다른 앱 기록과 섞이지 않고, "이 컴퓨터 초기화"를 누르면 함께 지워집니다.
- `AGA.close()`, `AGA.setTitle('모래 파기 (최고 12점)')`: 내 창을 닫거나 창 제목을 바꿉니다.
- `AGA.info()`: 방 주인 닉네임과 지금 친구 컴퓨터를 구경하는 중인지를 알려 줍니다.

아가라고요 밖에서 혼자 열었을 때도 오류가 나지 않고, 창과 관련된 기능은 조용히 넘어갑니다.

## 지킬 것

앱은 자기 폴더 안의 파일만 씁니다. 다른 앱 폴더나 `src/` 폴더의 파일은 건드리지 않습니다.
CSS나 전역 변수는 마음대로 써도 됩니다. 앱은 iframe이라는 별도의 창 안에서 돌아가서, 다른 앱이나 방 꾸미기와 섞이지 않습니다.

캔버스, DOM, p5.js 중 무엇을 써도 됩니다. 다만 npm이나 빌드 도구 없이 그대로 열리는 파일로 만들어 주세요.
라이브러리가 필요하면 `<script src="https://cdn.jsdelivr.net/...">`처럼 CDN 주소로 불러옵니다.

기록은 `AGA.save`로 저장해 주세요. localStorage를 직접 쓴다면 키 이름을 내 앱 id와 점으로 시작해야 합니다(`sand-dig.best`처럼).
모든 앱이 한 저장소를 같이 쓰기 때문에 이름이 겹치면 다른 앱의 기록을 덮어씁니다. 자동 점검(`python tools/check.py`)이 이 규칙을 확인합니다.

## 알아 두면 좋은 것

앱 창 안에는 마우스와 키보드 입력이 브라우저에서 그대로 들어갑니다. 예전에는 볼록 화면의 입력 보정 때문에 더블클릭과
오른쪽 클릭 메뉴가 앱 안으로 들어가지 않았지만, 2026-11-10 볼록 효과를 빼면서 이 제한도 없어졌습니다.

SDK를 불러온 앱은 아가라고요 창 안에서 기본 커서가 그 시절 모양의 화살표로 바뀝니다. 버튼처럼 누를 수 있는 곳에 손가락 커서를 쓰려면
`cursor: pointer` 대신 `cursor: var(--aga-hand, pointer)`라고 적어 주세요. 혼자 열었을 때는 뒤에 적은 `pointer`가 나옵니다.
쥔 손(`--aga-grab`, `--aga-grabbing`)과 모래시계(`--aga-wait`)도 같은 방식으로 쓸 수 있습니다.

`html, body { overflow: hidden }`과 머리줄의 `white-space: nowrap`은 지우지 마세요. 스크롤바가 생겼다 사라지거나 머리줄이 두 줄이 되면서
게임판이 떨리는 문제가 실제로 있었습니다(known-issues 12, 14). `AGA.fitCanvas`를 쓰면 나머지는 SDK가 알아서 막아 줍니다.

AI에게 앱을 만들어 달라고 할 때는 이 파일과 `apps/_template/index.html`을 같이 보여 주면 같은 형식으로 만들어 줍니다.
