# 요구 사항

아가라고요가 무엇을 해야 하는지 적은 문서입니다. 지금 레포에 들어 있는 기능과,
팀이 피그마의 "오브젝트/사운드"와 "워크플로우" 페이지에 정리한 계획을 바탕으로 적었습니다.
새로 정한 것이 생기면 이 문서를 먼저 고치고, 거기서 생긴 일은 `docs/tasks.md`에 더합니다.
사이트가 지금 어떻게 동작하는지는 `docs/guide.md`에, 올리기 전에 확인할 것은 `docs/checklists.md`에 있습니다.

## 목표

2000년대 개인 홈페이지를 "진짜 집 꾸미기"로 바꾼 웹사이트를 만듭니다.
사이트 전체가 옛 컴퓨터 한 대처럼 동작하고, 방 꾸미기와 미니게임은 그 컴퓨터 안의 앱으로 들어갑니다.
옛 홈페이지의 방명록, 다이어리, 사진첩, 즐겨찾기 링크가 하던 일은 방 안의 가구가 맡습니다.
주인은 가구마다 좋아하는 것을 담아 두고, 놀러 온 손님은 가구를 눌러 그것을 구경합니다.
웹프로그래밍 개론 팀 프로젝트이며, 만든 사이트는 https://agaragoyo.github.io/ 에 배포합니다.

## 기능

번호는 할 일과 확인 목록에서 이 요구 사항을 가리킬 때 씁니다. 상태 칸에는 지금 레포에 들어 있으면 "있음",
일부만 들어 있으면 "일부", 하기로 정했지만 아직 만들지 않았으면 "계획"이라고 적습니다.
팀에서 정하기 전에 써 보려고 사이트에 먼저 넣은 것은 "시험"이라고 적고, 팀 회의에서 그대로 둘지 정합니다.

| 번호 | 요구 사항 | 상태 |

| F1 | 처음 들어오면 꺼진 모니터가 보이고, 전원을 누르면 부팅과 로그인을 거쳐 바탕화면이 뜹니다. | 있음 |
| F2 | 처음 온 사람은 닉네임으로 사용자를 만들고, 다음부터는 자기 이름을 눌러 들어옵니다. | 있음 |
| F3 | 바탕화면 아이콘을 두 번 누르면 창이 열립니다. 창은 옮기기, 최소화, 최대화, 닫기가 되고 작업 표시줄에 늘어섭니다. | 있음 |
| F4 | 방 꾸미기에서 선반의 가구를 끌어다 방에 놓습니다. 놓은 가구는 다시 옮기거나 선반으로 치울 수 있고, 겹치거나 벽 밖으로 나가는 자리에는 놓이지 않습니다. 끌지 않고 가구를 한 번 눌러 집은 뒤 놓을 자리를 눌러도 됩니다(WCAG 2.2의 2.5.7). 들고 있는 동안 오른쪽 단추나 Esc 키를 누르면 가구가 제자리로 돌아갑니다. | 있음 |
| F5 | 꾸민 방은 브라우저에 바로 저장되고, 바탕화면 배경이 그 방 그림으로 바뀝니다. | 있음 |
| F6 | 바탕화면 배경의 방에 내 아바타가 삽니다. 바닥을 누르거나 방향키를 눌러 걷고, 아바타를 누르거나 Enter를 누르면 머리 위 말풍선으로 말합니다. 이 브라우저에서 아직 한 번도 말하지 않았으면 아바타 머리 위에 작은 말풍선 그림이 떠서 말할 수 있다는 것을 알리고, 처음 말하면 다시 뜨지 않습니다. 친구 집에 손님으로 놀러 가도 같습니다. 방 벽의 현관문을 두 번 누르면 아바타가 문 앞까지 걸어간 뒤 이웃집 목록 창이 뜹니다(F19). 현관문은 가구가 아니라 방 그림에 늘 있습니다. | 있음 |
| F7 | 바탕화면의 방에서 가구를 두 번 누르면 아바타가 그 옆으로 걸어가 가구를 씁니다. 지금은 스탠드와 탁상 조명이 밤과 낮을 바꾸고, 컴퓨터가 주인이 넣어 둔 웹 게임을 새 탭으로 열고, 게임기가 미니게임 목록을, 책장이 주인이 꽂아 둔 책을, 라디오가 주인이 넣어 둔 CD를, TV가 주인이 고른 영화와 TV 시리즈를, 코르크 보드가 손님이 붙인 쪽지를, 시험지가 주인이 낸 문제를 엽니다(코르크 보드와 시험지는 시험, F22, F35). 나머지 가구는 아래 "가구와 인터랙션"의 계획대로 늘립니다. | 일부 |
| F8 | 공유 링크로 들어온 손님은 그 방이 배경인 바탕화면에서 자기 아바타로 걸어 다니며 가구를 두 번 눌러 기믹을 써 봅니다. 가구를 옮기지는 못합니다. 손님의 바탕화면에는 방 꾸미기와 공유하기 대신 자기 사용자를 만들러 가는 "나도 만들기" 아이콘이 있습니다. 친구 집과 이웃집에서는 그 집 주인의 아바타가 이름표를 달고 방 가운데 가까운 빈칸에 서서 주인이 적어 둔 인사말을 한 번 말하고, 손님인 내 아바타는 빨간 옷을 입어 주인과 구분됩니다. | 있음 |
| F9 | 바탕화면의 게임 폴더와 게임기 화면에서 게임을 세 묶음으로 나눠 보여 줍니다. 묶음은 "미니게임"(이 컴퓨터에 원래 있는 작은 게임), "설치한 게임"(따로 만든 큰 게임을 창에 띄운 것), "추억의 플래시 게임"(새 탭에서 열림)이고, 두 화면의 순서와 이름이 같습니다. 게임은 창 안에 열고 기록은 게임마다 따로 저장합니다. 다른 사이트의 게임을 창에 띄우는 아이콘에는 마우스를 올리면 그 사이트 주소가 보입니다. | 있음 |
| F11 | 화면은 2005년 무렵의 은색 평면 브라운관 모니터와 그 시절 창 모양으로 보여 줍니다. 화면에는 아주 약한 깜빡임과 구석 그늘만 겹치고, 그레인, 가는 가로줄(스캔라인), 볼록하게 휘는 효과는 쓰지 않습니다. 모니터 아래 소리 단추를 누르면 그 시절 모니터처럼 화면에 OSD 상자가 잠깐 뜨고, 꺼진 화면에는 "신호 없음" 상자가 떠다니며, 켤 때는 자기 제거(디가우스)로 밝은 곳에 색이 2초 동안 번졌다가 가라앉으며 밝아지고, 끌 때는 그림이 곧바로 어두워집니다. | 있음 |
| F12 | 주인이 가구마다 좋아하는 것(링크, 사진, 글)을 넣어 두면, 가구를 쓸 때 그 내용이 뜹니다. 가구마다 무엇을 넣는지는 아래 "가구와 인터랙션"에 있습니다. 등록은 나중으로 미룰 수 있습니다. 주인은 내 컴퓨터에서 그 가구를 쓸 때 뜨는 화면에서 넣고 고치며, 넣은 것은 공유 링크에 담겨 손님 화면에도 뜹니다. 지금은 옛날 컴퓨터, 게임기, 책장, 라디오, TV에 넣을 수 있습니다. 바탕화면의 방에서는 주인이 무언가 담아 둔 가구 위에 작은 별이 깜박여서, 손님과 주인 모두 어느 가구를 눌러 볼 수 있는지 압니다. 쪽지가 서버에 있어 미리 알 수 없는 코르크 보드에는 뜨지 않습니다. | 일부 |
| F13 | 방 꾸미기에서 조명, 벽지, 바닥을 바꿉니다. 방 꾸미기 창 위쪽의 단추로 벽지는 기본 벽, 하트, 구름, 초록 줄무늬, 잔꽃무늬, 민트 줄무늬, 리본 가운데, 바닥은 기본 바닥, 파랑 체크, 분홍 체크, 빨강 체크, 나무, 분홍 나무, 헤링본 가운데 고르고, 바탕화면의 방과 손님 화면, 공유 링크, 내려받는 방 그림에 같이 담깁니다. 무늬는 팀이 그린 픽셀 벽지와 바닥 그림입니다. 조명은 아직 없습니다. | 일부 |
| F14 | 주인이 아바타의 모습을 꾸밉니다. 어디까지 꾸밀지는 아직 정하지 않았습니다. | 계획 |
| F15 | 전원부터 방, 방 꾸미기, 미니게임까지 상황마다 효과음과 배경음악이 납니다. 목록은 아래 "소리"에 있습니다. 모니터 아래 "소리" 버튼과 시작 메뉴로 모든 소리를 끄고 켜고, 배경음악 앱에서 내 방 곡을 고르거나 배경음악만 끕니다. | 있음 |
| F16 | 게임 폴더의 "추억의 플래시 게임" 묶음에 추억의 플래시 게임 여덟 개와 추억의 영상 하나를 넣습니다. 아이콘을 두 번 누르면 원작 사이트의 새 탭에서 열린다는 것과 주소를 알려 주고, "새 탭에서 열기"를 누르면 열립니다. 난이도가 나뉜 게임은 그 창에서 난이도를 골라 엽니다. | 있음 |
| F17 | 처음 온 사람은 튜토리얼로 침대와 스탠드를 직접 놓고, 스탠드를 써 보고, 아바타를 누르거나 Enter를 눌러 한마디 해 보고, 현관문으로 이웃집 목록 창을 열어 보며 사이트를 익힙니다. 튜토리얼에서 한 말은 숨은 기능의 암호로 듣지 않습니다. 언제든 건너뛸 수 있습니다. 시작 메뉴에서 다시 보면 저장된 방을 그대로 두고 빈 연습 방에서 첫 단계부터 해 볼 수 있습니다. | 있음 |
| F18 | 공유할 때 방 그림을 PNG로 내려받을지, 체험할 수 있는 방의 링크를 복사할지 고릅니다. 그림은 낮 모습의 내 방 한 장(2560×1440px)입니다. 그림에는 아바타도 들어가고, 아바타는 단추를 누를 때 서 있던 자리에 섭니다. | 있음 |
| F19 | 이웃집에 놀러 갑니다. 이웃집은 팀원이 배포 사이트에서 꾸미고 가구에 좋아하는 것을 담은 방의 공유 링크를 `data/neighbors.js`에 닉네임과 함께 넣은 것입니다. 이웃집의 방은 서버에서 받아 와서 주인이 방을 고치면 이웃집도 따라 바뀌고, 주인이 닉네임을 바꾸면(F28) 이웃집의 이름도 바뀝니다. 로그인 화면 오른쪽 단(친구 집)에는 이웃집이 사진 칸으로 한 줄에 세 집씩 늘어서고(사진 아래 이름 한 줄), 처음 온 사람도 빈 방을 꾸미기 전에 채워진 방을 먼저 볼 수 있습니다. 이 브라우저에서 올린 방은 내 사용자로 이미 있으므로 이웃집 칸에서는 뺍니다. 목록에 방의 복사본을 함께 적어 고정한 이웃집은 서버에 방이 없거나 서버에 닿지 못해도 남고, 그 방을 올린 브라우저에서는 이 컴퓨터 초기화와 링크 지우기를 쓸 수 없습니다. 방 벽의 현관문을 두 번 누르면 아바타가 문 앞까지 걸어간 뒤 이웃집 목록 창이 뜹니다. 창에는 이웃마다 주인 사진과 이름, "놀러 가기" 단추가 한 줄씩 있고, 단추를 누르면 그 집에 손님으로 들어갑니다. 지금 바탕화면에 있는 집은 목록에서 빠지고, 보여 줄 이웃이 없으면 창에 놀러 갈 수 있는 이웃집이 없다고 뜹니다. 손님 바탕화면에서 이 컴퓨터에 내 집이 있으면 "내 컴퓨터로" 아이콘으로 곧장 돌아오고, 없으면 "나도 만들기"로 사용자를 만듭니다. 이웃집은 로그인 화면과 목록 창에 여섯 집까지 나옵니다. | 시험 |
| F20 | 화면 보호기가 있습니다. 바탕화면을 2분 동안 그냥 두면 검은 화면 위로 주인의 인사말이 흘러가고, 마우스나 키를 누르면 걷힙니다. 인사말은 공유하기 창에서 30자까지 적고, 공유 링크에 같이 담겨 친구 화면에서도 흘러갑니다. 창을 쓰는 중이나 가구를 가까이 보는 중에는 돌지 않습니다. | 시험 |
| F21 | 공유하기에서 링크를 만듭니다. ## 가구와 인터랙션

팀 피그마의 오브젝트 표를 옮겼습니다(2026-11-03. 2026-11-09와 2026-11-10에 인터랙션 담당 1이 구체화한 가구를 다시 맞췄고, 2026-11-10에 비즈 발과 커튼도 피그마대로 고침). "주인이 넣는 것"은 방 주인이 가구에 담아 두는 내용이고,
"인터랙션"은 바탕화면의 방에서 가구를 두 번 누르거나 마우스로 건드렸을 때 일어나는 일입니다.
지금 레포에서 이 표대로 동작하는 가구는 스탠드, 옛날 컴퓨터, 게임기, 책장, 라디오, TV이고, 코르크 보드와 시험지는 시험으로 넣었습니다(F22, F35).
인터랙션이 아직 없는 가구는 두 번 누르면 아바타가 다가가 가구마다 다른 혼잣말 한 줄을 합니다(`data/furniture.js`의 `say`).

## 소리

파일은 팀 공유 드라이브에 모으고 있고, 2026-11-09에 받아서 `assets/sounds/`에 넣었습니다. 드라이브의 wav는 너무 커서(방 꾸미기 배경음악 하나가 약 41MB)

## 지켜야 할 것

기능과 상관없이 늘 지키는 조건입니다. 코드에서 지킬 자세한 규칙은 `AGENTS.md`의 "지켜야 할 것"에 있습니다.

- 빌드 도구나 npm, 프레임워크 없이 그대로 열리는 HTML, CSS, 자바스크립트로 만듭니다.
- 마우스를 쓰는 PC 화면을 기준으로 합니다. 휴대폰은 모니터를 옆으로 돌려 보여 주는 정도만 지원합니다.
- 저장은 브라우저(localStorage)에 합니다. 서버(Firebase)는 공유 링크(F21), 코르크 보드 방명록(F22, 시험), 이웃집의 방(F19), 아이디(F31, 시험)에만 씁니다. 서버가 막힌 날에는 방 그림 PNG(F18)로 방을 보냅니다.
  서버에 새 기능을 두기 전에는 "아직 정하지 않은 것"에서 방법부터 정합니다.
- 화면은 1280×840 고정 좌표의 무대에 그립니다.
- 주인이 넣은 글과 링크는 공유 링크를 연 손님의 화면에도 뜹니다. 그 글과 링크 때문에 손님의 화면에서 스크립트가 돌지 않게 합니다.
- 사이트가 누구에게나 공개되어 있으므로 소리와 그림은 써도 되는 것만 쓰고 출처를 남깁니다.
- 실제 윈도우의 로고와 이름, 다른 회사의 로고 색은 쓰지 않습니다.
- 남의 게임은 원작 주소로 이어 주기만 하고, 파일을 레포로 옮겨 오거나 그대로 베끼지 않습니다. 직접 만드는 게임은 같은 장르의 우리 게임으로 만듭니다.

  팀이 정한 뒤에 바로 넣습니다. 한번 보낸 링크와 서버에 올린 방은 스위치를 꺼도 되돌릴 수 없기 때문입니다.
