# 요구 사항

아가라고요가 무엇을 해야 하는지 적은 문서입니다. 지금 레포에 들어 있는 기능과,
팀이 2026-11-03에 피그마의 "오브젝트/사운드" 페이지에 정리한 계획을 바탕으로 적었습니다.
새로 정한 것이 생기면 이 문서를 먼저 고치고, 거기서 생긴 일은 `docs/tasks.md`에 더합니다.
사이트가 지금 어떻게 동작하는지는 `docs/guide.md`에, 올리기 전에 확인할 것은 `docs/checklists.md`에 있습니다.

## 목표

2000년대 개인 홈페이지를 "진짜 집 꾸미기"로 바꾼 웹사이트를 만듭니다.
사이트 전체가 옛 컴퓨터 한 대처럼 동작하고, 방 꾸미기와 미니게임은 그 컴퓨터 안의 앱으로 들어갑니다.
옛 홈페이지의 방명록, 다이어리, 사진첩, 즐겨찾기 링크가 하던 일은 방 안의 가구가 맡습니다.
주인은 가구마다 좋아하는 것을 담아 두고, 놀러 온 손님은 가구를 눌러 그것을 구경합니다.
웹프로그래밍 개론 팀 프로젝트이며, 만든 사이트는 https://agaragoyo.github.io/ 에 배포합니다.

| --- | --- | --- |
| 알파 | 11주차 | 아직 정하지 않았습니다 |
| 최종 발표 | 15주차 | 아직 정하지 않았습니다 |

## 기능

번호는 할 일과 확인 목록에서 이 요구 사항을 가리킬 때 씁니다. 상태 칸에는 지금 레포에 들어 있으면 "있음",
일부만 들어 있으면 "일부", 하기로 정했지만 아직 만들지 않았으면 "계획"이라고 적습니다.

| 번호 | 요구 사항 | 상태 |
| --- | --- | --- |
| F1 | 처음 들어오면 꺼진 모니터가 보이고, 전원을 누르면 부팅과 로그인을 거쳐 바탕화면이 뜹니다. | 있음 |
| F2 | 처음 온 사람은 닉네임으로 사용자를 만들고, 다음부터는 자기 이름을 눌러 들어옵니다. | 있음 |
| F3 | 바탕화면 아이콘을 두 번 누르면 창이 열립니다. 창은 옮기기, 최소화, 최대화, 닫기가 되고 작업 표시줄에 늘어섭니다. | 있음 |
| F4 | 방 꾸미기에서 선반의 가구를 끌어다 방에 놓습니다. 놓은 가구는 다시 옮기거나 선반으로 치울 수 있고, 겹치거나 벽 밖으로 나가는 자리에는 놓이지 않습니다. | 있음 |
| F5 | 꾸민 방은 브라우저에 바로 저장되고, 바탕화면 배경이 그 방 그림으로 바뀝니다. | 있음 |
| F6 | 바탕화면 배경의 방에 내 아바타가 삽니다. 바닥을 누르거나 방향키를 눌러 걷고, Enter를 누르면 머리 위 말풍선으로 말합니다. 바탕화면이 놀이터로 바뀌면 아바타도 같이 가고, 울타리의 아파트 문을 두 번 누르면 방으로 돌아옵니다. | 있음 |
| F7 | 바탕화면의 방에서 가구를 두 번 누르면 아바타가 그 옆으로 걸어가 가구를 씁니다. 지금은 스탠드와 가로등이 밤과 낮을 바꾸고, 창문이 바탕화면을 놀이터로 옮기고, 컴퓨터가 미니게임 폴더를 엽니다. 나머지 가구는 아래 "가구와 인터랙션"의 계획대로 늘립니다. | 일부 |
| F8 | 공유 링크로 들어온 손님은 그 방이 배경인 바탕화면에서 자기 아바타로 걸어 다니며 가구를 두 번 눌러 기믹을 써 봅니다. 가구를 옮기지는 못합니다. | 있음 |
| F9 | 미니게임 폴더에서 게임을 창 안에 열고, 기록은 게임마다 따로 저장합니다. | 있음 |
| F10 | 마우스 앱에서 커서의 색과 크기를 고르고, 화살표와 손가락 모양을 직접 그립니다. | 있음 |
| F11 | 모니터 위 스위치로 1998, 2005, 2010 모습을 바꿔 봅니다. 시대가 정해지면 하나만 남깁니다. | 있음 |
| F12 | 주인이 가구마다 좋아하는 것(링크, 사진, 글)을 넣어 두면, 가구를 쓸 때 그 내용이 뜹니다. 가구마다 무엇을 넣는지는 아래 "가구와 인터랙션"에 있습니다. | 계획 |
| F13 | 방 꾸미기에서 조명, 벽지, 바닥색을 바꿉니다. | 계획 |
| F14 | 주인이 아바타의 모습을 꾸밉니다. 어디까지 꾸밀지는 아직 정하지 않았습니다. | 계획 |
| F15 | 부팅부터 방, 방 꾸미기, 놀이터, 미니게임까지 상황마다 효과음과 배경음악이 납니다. 목록은 아래 "소리"에 있습니다. | 계획 |
| F16 | 미니게임 폴더에 추억의 플래시 게임 네 개를 넣습니다. 아이콘을 두 번 누르면 원작 사이트의 새 탭에서 열린다는 것과 주소를 알려 주고, "새 탭에서 열기"를 누르면 열립니다. | 있음 |

## 가구와 인터랙션

팀 피그마의 오브젝트 표를 옮겼습니다(2026-11-03). "주인이 넣는 것"은 방 주인이 가구에 담아 두는 내용이고,
"인터랙션"은 바탕화면의 방에서 가구를 두 번 누르거나 마우스로 건드렸을 때 일어나는 일입니다.
지금 레포에서 이 표대로 동작하는 가구는 스탠드뿐이고, 컴퓨터는 아직 미니게임 폴더를 엽니다.

| 가구 | 주인이 넣는 것 | 인터랙션 |
| --- | --- | --- |
| 게임기 | 준비된 미니게임 가운데 하나 | 컴퓨터 화면 안에 게임기 화면이 뜨고, 그 안에서 게임을 골라 합니다. |
| 라디오 | 앨범이나 플레이리스트 링크 | CD 그림이 늘어서고, 하나를 고르면 Spotify나 Apple Music과 이어진 곡 목록이 열려 1분 동안 미리 듣습니다. 누를 때는 재생 단추가 꾹 눌리는 입체적인 느낌을 줍니다. |
| 옛날 컴퓨터 | 좋아하는 웹 게임 링크 | 그 게임이 어느 사이트의 새 탭에서 열리는지 알려 주고, "새 탭에서 열기"를 누르면 링크가 열립니다. |
| TV | 영화나 TV 시리즈의 링크, 포스터, 짧은 추천 이유 | 넷플릭스 큐레이션처럼 작품을 스크롤로 넘겨 봅니다. 작품을 넣을 때는 이름, 연도, 감독으로 찾는 검색 단계를 거칩니다. |
| 책장, 테이블 위의 책 | 책 제목, 표지, 좋아하는 구절이나 고른 이유 | 책 창이 뜹니다. 창에는 책 디자인 안의 정해 둔 자리에 맞춘 표지, 같은 작가의 다른 추천 책, 옆 책으로 넘어가는 앞뒤 단추가 들어갑니다. |
| 옷장 | 위시리스트 상품 링크 여러 개 | 쓸 때마다 넣어 둔 링크 가운데 하나가 무작위로 열립니다. |
| 디카 | 사진과 짧은 설명 | 포토부스로 사진을 찍고, 액정이 켜지면 단추로 사진을 넘겨 봅니다. |
| 다이어리 | 주인만 쓸 수 있는 짧은 글 | 주인이 쓴 짧은 글이 뜹니다. |
| 비즈 발, 커튼 | 색과 모양 | 마우스가 스치면 흔들리며 달그락거리고, 사람이 지나가듯 양옆으로 벌어집니다. |
| 냉장고 | 최애 간식 링크(정하는 중) | 문이 열리며 간식 링크로 갑니다. |
| 화초 | 화초 이름과 식물 종류 | 이름과 종류가 뜨고 잎이 펄럭입니다. 물을 줄 수 있고, 언제 줬는지 달력에서 봅니다. |
| 포스터 | 좋아하는 영화, 드라마, 애니메이션, 아티스트의 포스터 이미지와 별점, 고른 이유 | 주인이 매긴 별점과 이유가 뜹니다. |
| 코르크 보드 | 주인이 아니라 손님이 남기는 닉네임과 메시지 | 손님이 포스트잇이나 스티커에 방명록을 남깁니다. |
| 스탠드 | 없음 | 조명을 켜고 끕니다. |
| 침대, 식탁, 소파 | 없음 | 따로 정한 인터랙션이 없고, 지금처럼 아바타가 가구 이름을 말합니다. |
| 펫 | 키울 동물(강아지, 고양이, 햄스터, 코끼리, 코알라, 공룡 등) | 쓰다듬거나 물과 밥을 줍니다. 넣을지 정하지 않아 보류합니다. |

## 추억의 플래시 게임

피그마에 미니게임으로 넣을 추억의 플래시 게임 네 개가 있습니다. 모두 남이 만든 게임이므로 파일을 레포로 옮겨 오거나 그대로 베끼지 않고 원작 주소로 이어 줍니다.
처음에는 레포 밖 기존 게임처럼 창 안에 띄우려 했습니다. 그런데 세 게임이 있는 와플래시 게임 아카이브의 플레이어는 다른 사이트의 창 안에서 게임을 시작하지 않았고,
friv.com은 다른 사이트가 창에 띄우는 것을 막아 두었습니다. 그래서 네 게임 모두 새 탭으로 엽니다(2026-11-03). 아카이브는 공식 주소인 waflash.org로 잇습니다.

아직 고르지 않은 소리는 "고르는 중"으로 적었습니다. `enter.aiff`는 크롬과 파이어폭스에서 재생되지 않으므로

## 지켜야 할 것

기능과 상관없이 늘 지키는 조건입니다. 코드에서 지킬 자세한 규칙은 `AGENTS.md`의 "지켜야 할 것"에 있습니다.

- 빌드 도구나 npm, 프레임워크 없이 그대로 열리는 HTML, CSS, 자바스크립트로 만듭니다.
- 마우스를 쓰는 PC 화면을 기준으로 합니다. 휴대폰은 모니터를 옆으로 돌려 보여 주는 정도만 지원합니다.
- 지금은 서버 없이 동작합니다. 저장은 브라우저(localStorage)에 하고, 공유할 방은 링크 주소에 담습니다.
  서버가 있어야 하는 기능은 만들기 전에 "아직 정하지 않은 것"에서 방법부터 정합니다.
- 화면은 1280×840 고정 좌표의 무대에 그립니다.
- 시대가 정해지기 전까지는 세 시대에서 모두 동작해야 합니다. 클릭을 받는 기능은 1998 볼록 화면에서도 맞게 눌려야 합니다.
- 주인이 넣은 글과 링크는 공유 링크를 연 손님의 화면에도 뜹니다. 그 글과 링크 때문에 손님의 화면에서 스크립트가 돌지 않게 합니다.
- 사이트가 누구에게나 공개되어 있으므로 소리와 그림은 써도 되는 것만 쓰고 출처를 남깁니다.
- 실제 윈도우의 로고와 이름, 다른 회사의 로고 색은 쓰지 않습니다.
- 남의 게임은 원작 주소로 이어 주기만 하고, 파일을 레포로 옮겨 오거나 그대로 베끼지 않습니다. 직접 만드는 게임은 같은 장르의 우리 게임으로 만듭니다.
- 사용자가 누르기 전에 결과를 알 수 있게 합니다. 새 탭이 열리거나 다른 사이트로 가거나 무언가 지워지는 동작은 먼저 그 사실을 보여 주고,
  확인 창의 단추는 "예/아니오" 대신 "새 탭에서 열기"처럼 결과를 말하는 이름으로 씁니다.
- 레포는 공개입니다. 팀원 실명, 비밀번호, API 키는 올리지 않습니다.

## 아직 정하지 않은 것

회의에서 정할 것을 모았습니다. 정해지면 아래 "정한 것"으로 날짜와 함께 옮기고, 이 목록에서는 지웁니다.

- 1998, 2005, 2010 가운데 어느 시대로 갈지 정합니다. 주소 뒤에 `?era=1998`처럼 붙이면 시대별 모습을 비교해 볼 수 있습니다.
- 방을 지금처럼 비스듬히 내려다볼지, 정면에서 보는 평면으로 바꿀지 정합니다.
- 생성형 이미지로 만들 가구 그림의 그림체와 크기를 정합니다.
- 알파와 최종 발표에서 각각 무엇까지 보여 줄지 정합니다.
- 코르크 보드 방명록은 손님이 쓴 글이 주인에게 전해져야 해서 지금처럼 서버 없이는 만들 수 없습니다.
  무료 저장 서비스를 붙일지, 방명록의 방식을 바꿀지 정합니다.
- 디카 사진은 크기가 커서 공유 링크 주소에 담을 수 없습니다. 사진을 어디에 저장하고 손님에게 어떻게 보여 줄지 정합니다.
- TV에서 작품을 이름, 연도, 감독으로 찾으려면 바깥 영화 정보 서비스가 필요합니다. 그런 서비스는 대부분 API 키를 요구하는데
  키는 공개 레포에 넣을 수 없으므로, 키 없이 쓸 수 있는 서비스를 찾을지 검색 단계를 뺄지 정합니다.
- 라디오는 Spotify와 Apple Music의 공식 플레이어를 키 없이 붙일 수 있지만, 미리 듣기 길이는 서비스가 정하므로
  1분보다 짧을 수 있습니다. 미리 듣기를 그 길이에 맞출지 정합니다.
- 냉장고에 무엇을 넣을지, 펫을 넣을지 정합니다.
