# 할 일

팀의 할 일을 한곳에 모은 목록입니다. 새로 정한 일은 여기에 더하고, 끝난 일은 상태를 "끝"으로 바꿉니다.
공개 레포라서 담당은 실명 대신 역할로 적습니다. 역할은 2026-11-03 팀 피그마의 역할 분담을 옮긴 것이고,
팀원이 레포에 들어오면 GitHub 아이디를 함께 적습니다. 작업의 자세한 내용은 `worklog/`의 일지에 남기고, 여기에는 한 줄만 둡니다.
F로 시작하는 번호는 `docs/requirements.md`의 요구 사항 번호이고, 상태는 할 일, 하는 중, 기다림, 끝 가운데 하나로 적습니다.
