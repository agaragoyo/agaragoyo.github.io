# 2026-10-27 세션 로그

## 요약
웹프로그래밍 개론 팀 프로젝트(아가라고요) 기획 문서를 분석하고, 다음 주 수업 때 팀원에게 보여 줄 뼈대 데모를 만들었다.
범위는 사용자 지시에 따라 최소한으로 잡았다. 기믹, 소리, 임베드, 미니게임은 넣지 않았다.

## 주요 변경
- `index.html`, `style.css`: CRT 모니터 테두리, 그레인과 스캔라인, 볼록 효과, 전원 버튼 연출, 시작 화면(닉네임)
- `src/config.js`: 격자 40px, 32×18칸, 벽 11줄과 바닥 7줄, 선반 높이 등 기본값
- `data/furniture.js`: 가구 8개 목록 (크기, 구역, 임시 색)
- `src/rules.js`: 배치 규칙 (벽/바닥 구역, 같은 층 겹침 금지, 책상 위에 'top' 가구 올리기)
- `src/room.js`: 가구 그리기, 끌어 놓기, 격자 스냅, 책상을 옮기면 위 물건도 같이 이동, 선반에 놓으면 치우기
- `src/shelf.js`: 하단 가구 선반 (화살표, 휠로 넘기기)
- `src/win.js`: 옛 OS 모양 창 (열기, 닫기, 끌어 옮기기). 가구를 누르면 빈 자리 창이 뜬다
- `src/share.js`: localStorage 자동 저장, `#room=` 공유 링크(base64url JSON), 저장본과 링크 검사
- `src/main.js`: 화면 맞추기, 전원, 꾸미기/구경 모드 전환
- `.claude/launch.json`: 로컬 서버(python http.server 8123)
- `known-issues.md`: 겹침 버그, 404 안내, file:// 문제

## 결정 사항
- 공유 링크 압축은 lz-string 대신 base64url로 했다. 가구 5개 링크가 166자라 라이브러리가 필요 없다.
- 창 모양은 98.css 없이 직접 CSS로 그렸다. 외부 의존을 폰트(Galmuri, jsDelivr) 하나로 줄였다.
- 같은 가구를 여러 개 놓을 수 있게 했다. 방 상태 항목은 가구 id와 좌표만 갖는다.
- 정면 시점에서 바닥 가구는 밑변이 바닥 줄에 닿으면 되고 윗부분은 벽 영역으로 올라가도 된다. 벽 가구와 바닥 가구는 서로 겹쳐도 된다.
- 전원은 사용자가 직접 눌러 켜게 했다. 나중에 소리를 넣을 때 브라우저의 첫 클릭 제약을 자연스럽게 푼다.
- 가구 이미지는 `assets/furniture/<id>.png`가 있으면 쓰고, 없으면 색 상자에 이름을 적는다. 임시 PNG로 교체가 되는 것을 확인했다.
- 기획 문서(`*기획안*.md`)는 개인 메모라 `.gitignore`로 레포에서 뺐다.

## 세션 4: 아이소메트릭 방과 실제 화면 왜곡

### 요약
방을 싸이월드 미니룸 같은 2:1 아이소메트릭(왼쪽 벽, 오른쪽 벽, 마름모 바닥)으로 바꿨다.
볼록 효과는 비네팅 흉내 대신 SVG 필터로 화면을 실제로 휘고, 클릭은 보정 층으로 휘기 전 위치에 전달한다. 그레인도 새로 만들었다.

### 주요 변경
- `src/iso.js` (새 파일): 바닥 칸과 벽 좌표의 투영과 역투영, 벽과 바닥 SVG, 가구 임시 모양(입체 상자, 기울인 액자)
- `src/config.js`, `data/furniture.js`: 바닥 12×12칸(72×36px), 벽 7줄(36px). 바닥 가구는 [가로, 세로 칸]과 높이(px)
- `src/rules.js`, `src/room.js`, `src/shelf.js`: 아이소메트릭 배치 규칙과 드래그. 벽 가구는 왼쪽, 오른쪽 벽 어디든 건다
- `src/share.js`: 방 상태와 링크 형식 v2 (벽 가구에 `wall` 추가). 저장 키도 `agarago.room.v2`로 바꿔 옛 방은 버린다
- `src/crt.js` (새 파일): 왜곡 지도 생성, 입력 보정 층, 캔버스 그레인
- `tools/serve.py`: 캐시 금지 개발 서버. `.claude/launch.json`도 이걸로 바꿨다

### 결정 사항
- 시점은 사용자 요청과 기획의 "2000년대 개인 홈페이지" 콘셉트에 맞춰 싸이월드 미니룸식 아이소메트릭으로 정했다. 아트 팀 확정 전 데모용이다.
- 벽 가구 그림은 평평하게 그려도 코드가 skewY로 벽에 맞춰 기울인다. 바닥 가구 그림은 아이소메트릭으로 그려야 하고, 상자 크기는 `iso.js`의 `boxSize`를 따른다.
- 왜곡은 PC(마우스)에서만 켠다. 폰과 아이폰 사파리는 지금 고려하지 않는다(사용자 지시).
- 왜곡 세기 K=0.06. 모서리 네 곳에서 화면에 그려진 위치와 보정 공식이 2px 안으로 맞는 것을 확인했다.
- 1920×1080 에뮬레이션에서 가구를 끄는 동안 프레임 시간 95백분위가 왜곡을 켜면 9.0ms, 끄면 8.6ms였다.

## 세션 5: 아가라고요 OS (부팅, 로그인, 바탕화면, 앱)

### 요약
사이트 전체를 컴퓨터 한 대로 바꿨다. 전원을 켜면 부팅, 로그인, 바탕화면 순서로 진행하고, 방 꾸미기는 앱 하나가 됐다.
미니게임 폴더에는 김수민의 기존 게임 6개와 예시 앱을 넣었고, 팀원이 앱을 붙이는 형식(iframe + SDK)을 만들었다.

### 주요 변경
- `src/os.js` (새 파일): 부팅, 로그인(XP식 사용자 목록, 손님 구경), 바탕화면 아이콘, 작업 표시줄, 시작 메뉴, 앱 실행, SDK 메시지
- `src/win.js`: 창 관리자로 다시 씀 (최소화, 최대화, 작업 표시줄 버튼, 제목 줄 두 번 눌러 최대화)
- `src/apps/room-app.js` (새 파일): 방 꾸미기를 창 크기에 맞춰 줄여 보여 주는 앱
- `data/apps.js` (새 파일): 앱 목록. `apps/aga-sdk.js`, `apps/sample-click/`, `apps/README.md`: 팀원용 형식과 예시
- `src/crt.js`: iframe 안으로 보정한 입력 넣기, 다른 사이트 iframe은 보정 층에 구멍, 포인터 캡처 흉내
- `src/main.js`: 모니터 일만 남기고 화면 안쪽은 os.js로 넘김. 전원 연출 타이머 대비책
- `style.css`, `index.html`: 모니터 테두리 질감, 화면 턱, 스피커 구멍. OS 화면들의 스타일

### 결정 사항
- 앱 형식은 98.js, Windows 93, Puter처럼 "독립 HTML 페이지를 iframe으로" 띄운다. 팀원 코드가 서로 섞이지 않고, 혼자 열어 개발할 수 있기 때문이다.
- 김수민 게임들은 soomin007.github.io에 있어 배포된 데모와 같은 사이트다. 그래서 배포본에서는 보정이 iframe 안까지 정확히 들어간다.
  로컬(localhost)이나 나중에 팀 Organization으로 옮기면 다른 사이트가 되어 구멍 방식(보정 없음)으로 바뀐다.
- 방 안의 컴퓨터 가구를 누르면 미니게임 폴더가 열린다 (처음 기획의 "컴퓨터 = 미니게임 모음").
- 바탕화면 배경은 지금 꾸민 방 그림이다 (처음 기획의 "방에 따라 바뀌는 배경화면"의 첫 형태).
- 더블클릭은 보정 층이 넘기지 않으므로 아이콘과 제목 줄은 클릭 간격(400ms)으로 직접 판정한다.

- 미니게임은 수박게임, 사과게임을 베끼지 않고 같은 장르의 우리 게임으로 만들었다(이삿짐 합치기, 바탕화면식 네모 선택으로 합 10 파일 지우기).

## 세션 7: 베젤 각지게, 가구 돌리기

- `style.css`: 베젤 바깥(2u)과 화면 쪽(2u, 볼록 켜도 3u) 모서리를 거의 직각으로. 화면 둘레 비탈(box-shadow 38u)이 버튼 줄을 덮던 문제는
  `.controls`에 같은 만큼 padding-top을 주어 해결했다. 이때 같은 규칙 아래쪽의 `padding` 단축 속성이 padding-top을 덮어써서 축별 속성으로 나눴다(전역 규칙의 그 함정).
- 가구 돌리기: 바닥 가구에 `r: 1`을 두면 가로와 세로 칸 수가 바뀐다(`rules.js`의 `dims`). 끄는 동안 R 키(한글 자판 ㄱ 포함)나 마우스 휠로 돌린다.
  그림은 `<id>-r.png`가 있으면 쓰고, 없으면 원래 그림을 좌우로 뒤집는다. 위에 물건을 얹은 책상과 정사각형 가구는 돌리지 않는다. 공유 링크는 네 번째 칸에 1을 넣는다.
