# 2026-11-01 팀원 앱의 공통 기반 (soomin007)

## 한 일
팀원 누구나 같은 방식으로 앱을 만들도록 SDK에 공통 도우미를 넣고, 복사해서 시작하는 앱 틀을 만들었다.
가구를 눌렀을 때만 열리는 앱을 목록에 넣는 방법(`folder: 'furniture'`)도 정했다.

## 바꾼 파일
- `apps/aga-sdk.js`: `AGA.id`, `AGA.load/save`(키 앞에 앱 id를 붙여 localStorage에), `AGA.fitCanvas`(게임판 맞추기와 `board.point`)
- `apps/_template/index.html`(새 파일): 점을 누르는 작은 게임. 그리기, 입력, 기록 저장, 창 닫기가 SDK로 연결된 틀
- `apps/tidy-up`, `apps/file-ten`: 두 게임에 똑같이 들어 있던 맞추기 코드와 localStorage 코드를 SDK 도우미로 바꿨다(저장 키는 그대로)
- `apps/README.md`: 틀에서 시작하기, 가구에 붙이기, SDK 목록
- `data/apps.js`: `folder: 'furniture'` 설명, 틀 안내

## 정한 것과 이유
- 게임마다 되풀이되던 함정(스크롤바 진동, 소수점 크기, 저장 키 충돌)을 문서로 당부하는 대신 SDK 한곳에서 막았다.
- 틀은 실제로 돌아가는 가장 작은 게임으로 만들었다. 팀원이나 AI가 이 파일을 보고 같은 모양으로 만들기 쉽다.
- 가구 전용 앱은 새 필드를 만들지 않고 기존 `folder` 값 하나를 더 쓰게 했다. 바탕화면과 폴더는 원래 `folder`로 걸러지므로 OS 코드를 고칠 필요가 없다.
- 확인: 틀을 혼자 열어 점을 눌러 점수와 기록 저장, 아가라고요 안에서 짐 정리와 파일 정리 10이 예전 최고 기록(5, 3)을 그대로 읽고 게임판을 정수 크기로 맞추는 것을 봤다.

## 남은 일과 알아 둘 것
- 가구 전용 앱은 아직 하나도 없다. 첫 기믹 앱이 들어오면 실제로 가구에서 열리는지 확인한다.
