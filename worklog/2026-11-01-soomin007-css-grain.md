# 2026-11-01 그레인을 CSS 애니메이션으로 (soomin007)

## 한 일
화면 그레인이 화면 절반 크기의 캔버스를 1초에 24번 새로 칠하고 있었다(1998, 2005에서 그레인을 켜 두는 동안 계속).
노이즈 그림 한 장(128×128)만 처음에 만들고, CSS가 그 그림을 1초에 24번 다른 자리로 건너뛰게 옮기도록 바꿨다.

## 바꾼 파일
- `src/crt.js`: 캔버스 프레임 8장과 setInterval을 없애고, 노이즈 타일 한 장을 `--grain-img`로 넣는다
- `style.css`: `.fx-grain::before`가 타일을 깔고 `grain-jump` 키프레임(8곳, steps)으로 옮긴다. 움직임 줄이기 설정이면 멈춘다
- `index.html`: `#grain`을 canvas에서 div로
- `src/main.js`: 더는 쓰지 않는 `isGrainOn`

## 정한 것과 이유
- 같은 노이즈라도 타일 크기와 맞지 않는 거리만큼 옮기면 새 노이즈처럼 보인다. transform만 바뀌므로 브라우저는 다시 칠하지 않고 합성만 한다.
- 그레인을 보이고 숨기는 것은 원래대로 CSS(`body:not(.grain)`, 2010의 `.fx` 숨김)가 맡는다.
- 확인: 로컬에서 애니메이션이 돌고 있는지, 그레인을 진하게 해서 화면 전체를 고르게 덮는지(타일 이음매가 보이지 않는지) 봤다.

## 남은 일과 알아 둘 것
- 그레인은 진하기 7%에 overlay라 차이가 거의 보이지 않아야 정상이다. 낡은 노트북에서 팬 소리나 버벅임이 줄었는지는 사람이 봐 주면 좋다.
