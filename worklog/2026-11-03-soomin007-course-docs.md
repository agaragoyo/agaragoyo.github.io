# 2026-11-03 요구 사항, 할 일, 확인 목록 문서 (soomin007)

## 한 일
10주차 수업활동이 레포에 요구하는 `docs/requirements.md`, `docs/tasks.md`, `docs/checklists.md`를 새로 썼다.
요구 사항과 할 일은 지금 레포에 들어 있는 기능과, 팀 피그마의 "오브젝트/사운드" 페이지에 정리된 회의 결과를 옮긴 것이다.
확인 목록은 AGENTS.md와 known-issues에 흩어진 규칙 가운데 사람이 직접 봐야 하는 것만 모았다.

## 바꾼 파일
- `docs/requirements.md`: 새 문서. 기능 F1~F16과 상태, 가구와 인터랙션, 추억의 플래시 게임, 소리, 지켜야 할 것, 아직 정하지 않은 것과 정한 것
- `docs/tasks.md`: 새 문서. 역할 분담을 옮긴 할 일과 담당, 상태
- `docs/checklists.md`: 새 문서. PR 전, 화면, 가구 기믹, 소리와 그림, 앱, AI 도구, 합치기 전, 발표 전에 볼 것
- `AGENTS.md`: 작업 시작 전에 요구 사항과 할 일을 보게 하고, 남의 게임은 원작 주소로 이어 준다는 규칙을 더함
- `README.md`: 세 문서 안내, 남의 게임을 원작 주소로 잇는 규칙
- `docs/guide.md`: "아직 정하지 않은 것" 목록을 requirements로 옮기고 안내만 남김
- `docs/file-map.md`: 세 문서를 더함

## 정한 것과 이유
- 공개 레포라서 담당은 실명 대신 역할 이름(Admin, 이미지 담당, 가구 그림 담당, 인터랙션 담당 1과 2, 사운드 담당)으로 적었다.
- 추억의 플래시 게임은 남의 게임이라 레포 밖 게임처럼 원작 주소를 여는 앱으로 넣기로 했다. 확인해 보니 vidkidz 주소는 창 안에 뜨지만,
  friv.com은 `frame-ancestors`로 다른 사이트가 창 안에 띄우는 것을 막아 두어서 Fireboy and Watergirl은 방법을 따로 정한다.
- 정해야 할 것이 guide와 requirements 두 곳에 있으면 서로 어긋나므로 requirements 한 곳에 모았다.
- 방명록, 디카 사진, TV 검색은 지금 구조(서버가 없고, 공개 레포라 API 키를 둘 수 없음)로는 막히는 곳이 있어서 만들기 전에 정할 것으로 적었다.
- 피그마 주소와 소리 파일을 모아 둔 공유 폴더 주소는 팀 안에서 쓰는 주소라 문서에 넣지 않았다.
