# 2026-11-03 추억의 플래시 게임 네 개를 새 탭으로 (soomin007)

## 한 일
피그마에서 고른 추억의 플래시 게임 네 개(슈의 라면가게, 감옥탈출, 눈빛보내기, Fireboy and Watergirl)를 미니게임 폴더에 넣었다.
남의 게임이라 파일을 옮겨 오지 않고 원작 주소로 잇는다. 창 안에서는 게임이 시작되지 않아서, 앱 목록에 새 탭으로 여는 종류(`href`)를 새로 만들었다.
이런 아이콘에는 새 탭으로 열린다는 화살표가 붙고, 두 번 누르면 어느 사이트의 새 탭에서 열리는지 알려 주는 작은 창이 뜬다. "새 탭에서 열기"를 누르면 열린다.

## 바꾼 파일
- `src/apps/link-app.js`: 새 파일. `href` 앱이 새 탭에서 열린다는 것과 주소를 보여 주고 링크로 연다
- `src/apps/index.js`, `src/os.js`: `openLinkApp`을 등록하고 `os.openApp`에서 `href`면 그쪽으로 보냄, 아이콘에 바깥 화살표(`external`)와 마우스를 올리면 뜨는 설명
- `src/apps/folder-app.js`: 미니게임 폴더 창이 아이콘 줄 수에 맞춰 커짐(게임이 11개가 되며 셋째 줄이 아래 안내 글과 겹쳤다)
- `data/apps.js`: `href` 필드 설명, 플래시 게임 네 줄(그림 없이 색 타일)
- `tools/check.py`: `href`가 https 주소인지, `src`와 같이 쓰지 않았는지 봄
- `style.css`: 단추 줄(`.link-row`), 아이콘의 바깥 화살표, 폴더 아이콘 칸이 넘치면 스크롤
- `AGENTS.md`, `README.md`, `docs/file-map.md`, `docs/guide.md`, `docs/checklists.md`, `docs/requirements.md`, `docs/tasks.md`: `href` 앱, 플래시 게임, 누르기 전에 결과를 알리는 규칙
- `known-issues.md`: 31번(다른 사이트 게임이 창 안에서 시작되지 않는다), 32번(확인 창만 보고는 누른 뒤에 무슨 일이 일어날지 알 수 없었다)

## 정한 것과 이유
- 처음에는 레포 밖 기존 게임처럼 창(`src`)에 띄웠다. 아카이브 페이지는 창에 떴지만 게임 화면이 검은 채로 남았고, 아무것도 없는 시험용 iframe에서도 같았다.
  friv.com은 `frame-ancestors`로 창에 띄우는 것 자체를 막는다. 그래서 새 탭으로 여는 쪽을 골랐다.
- 처음에는 피그마의 옛날 컴퓨터 계획대로 "플레이 하시겠습니까? 예/아니오"만 물었다. 그것만으로는 새 탭이 열린다는 것을 알 수 없다는 지적을 받아,
  결과(새 탭이 열린다, 어느 사이트로 간다)를 먼저 보여 주고 단추를 "새 탭에서 열기"와 "취소"로 바꿨다.
  "이 탭은 그대로 남는다" 같은 안내도 한때 넣었지만 당연한 말이라 구구절절하다는 지적을 받고 뺐다.
  아이콘에도 바깥 화살표를 달아 누르기 전부터 알 수 있게 했다. 이 원칙은 AGENTS.md와 known-issues 32에 규칙으로 남겼다.
- 새 탭은 `window.open` 대신 진짜 링크(`target="_blank"`)로 연다. 사람이 누른 링크는 팝업 차단에 걸리지 않고, 마우스를 올리면 브라우저가 주소를 보여 준다.
  창은 링크가 열린 다음에 닫는다. 누르는 도중에 링크를 화면에서 빼면 브라우저가 링크를 따라가지 않는다.
- 주소는 피그마에 적힌 vidkidz.tistory.com 대신 아카이브가 안내하는 공식 주소 waflash.org로 넣었다. 같은 글 번호로 같은 게임이 열린다.
- 아이콘은 원작 그림을 가져다 쓰지 않으려고 색 타일(제목 첫 글자)로 두었다.

## 남은 일과 알아 둘 것
- 새 탭으로 열리므로 1998 볼록 화면과 상관없이 게임은 평평하게 보인다.
- 아카이브 페이지가 iframe 안에서 게임을 시작하지 않는 이유는 확인하지 못했다. 나중에 창으로 띄우고 싶으면 그 원인부터 찾는다.
- 1998 볼록 화면에서는 아이콘 위에 마우스를 올려도 설명(title)이 뜨지 않는다. 진짜 마우스가 보정 층 위에 있기 때문이다. 바깥 화살표는 그대로 보인다.
