# 2026-11-03 핀치 줌 중에는 볼록 화면 끄기 (soomin007)

## 한 일
맥 크롬에서 트랙패드로 화면을 확대하면 1998의 볼록 화면이 깨진다는 제보가 있었다. 윈도우 크롬에서는 Ctrl과 +, -, 터치패드 확대 모두 재현되지 않았다.
원인을 확인할 수 없어서, 핀치 줌으로 화면을 키운 동안에는 볼록 효과를 끄고 평평하게 보여 주게 했다. 1배로 돌아오면 다시 휜다.

## 바꾼 파일
- `src/main.js`: `isWarpOn`에 핀치 줌 조건을 더하고, `visualViewport`의 resize가 오면 화면 효과를 다시 정한다
- `docs/guide.md`, `docs/file-map.md`: 볼록 화면 설명
- `known-issues.md`: 29번

## 정한 것과 이유
- 브라우저 확대(Cmd와 +)는 창 크기 이벤트가 와서 지금도 왜곡 지도를 새 크기로 다시 만든다. 핀치 줌은 그 이벤트가 오지 않고, 제보도 트랙패드였던 것으로 보여 핀치 줌만 막았다.
- 맥에서만 끄지 않고 모든 PC에서 끈다. 운영체제를 가려내는 코드는 틀리기 쉽고, 확대해서 보는 동안에는 평평한 화면이 글자도 또렷하다.
- 확대하는 동안 창 자리(볼록 화면에서 위와 양옆 5% 안쪽)는 그대로 둔다. 손가락을 움직이는 사이에 창까지 움직이면 더 어지럽다.

## 남은 일과 알아 둘 것
- 맥이 없어서 실제 핀치 줌으로는 확인하지 못했다. 로컬 서버에서 `visualViewport.scale`을 2로 바꾸고 resize를 보내면 필터와 보정 층이 꺼지고,
  1로 돌리면 다시 켜지는 것까지 확인했다. 맥 사용자에게 다시 확인을 받아야 한다.
- 브라우저 확대(Cmd와 +)에서도 깨진다면 그때 다시 본다.
