# 2026-11-03 볼록 화면은 크롬 계열에서만 휨 (soomin007)

## 한 일
맥 사파리에서 1998 볼록 화면이 접속하자마자 왼쪽 위만 그려지고 나머지가 검게 남는다는 제보가 있었다.
화면을 실제로 휘는 효과를 확인한 엔진인 크롬 계열에서만 켜고, 사파리와 파이어폭스는 평평한 화면에 가장자리 그림자와 반사광(`.fx-curve`)만 보여 주게 했다.
앞서 "맥 크롬에서 핀치 줌을 하면 깨진다"로 받은 제보도 같은 사파리 문제였어서 설명을 바로잡았다.

## 바꾼 파일
- `src/main.js`: `CHROMIUM` 판정을 더하고 `isWarpOn`에서 크롬 계열일 때만 휘기를 켬, 핀치 줌 주석 바로잡음
- `style.css`: 2010의 창, 작업 표시줄, 시작 메뉴의 `backdrop-filter` 앞에 `-webkit-backdrop-filter`를 같이 씀
- `docs/guide.md`: 화면 효과 절에 휘는 브라우저와 평평한 브라우저, 핀치 줌 이유를 바로잡음
- `docs/checklists.md`: 화면 전체 효과를 고치면 사파리와 파이어폭스에서도 보라는 항목
- `known-issues.md`: 29번(핀치 줌) 바로잡음, 30번(사파리에서 1998 볼록 화면이 왼쪽 위만 그려진다) 추가

## 정한 것과 이유
- 처음에는 사파리만 빼려 했지만, 제보가 나오기 전까지는 어느 브라우저가 깨지는지 알 수 없다. 그래서 확인한 크롬 계열에서만 켜는 쪽으로 바꿨다.
  파이어폭스는 확인하지 못했을 뿐 깨진다는 근거는 없다. 확인되면 조건에 더하면 된다.
- 판정은 사용자 에이전트에 `Chrome/`가 있는지로 한다. 크롬, 엣지, 웨일, 삼성 인터넷, 오페라가 해당하고, 사파리와 파이어폭스, 아이폰과 아이패드의 모든 브라우저(엔진이 WebKit)는 빠진다.
- 사파리에서만 다르게 휘어 그리는 방법은 없다. CSS 변형으로는 가장자리를 볼록하게 휠 수 없다.
- 핀치 줌 동안 끄는 규칙은 남겼다. 확대 배율로 화면 전체 필터를 다시 그리는 부담을 피하고, 확대해서 볼 때는 평평한 화면이 더 또렷하다.
- 이 PC에는 사파리와 파이어폭스가 없어 두 브라우저의 화면은 직접 보지 못했다. 크롬에서 1998이 그대로 휘는지와 판정식이 사용자 에이전트별로 맞는지만 확인했다.

## 남은 일과 알아 둘 것
- 맥이 있는 팀원에게 사파리로 1998을 켜서 화면이 평평하게 끝까지 그려지는지 확인을 받는다.
- 크롬에서도 다른 사이트 게임 창은 1998에서 휘지 않아 창 테두리와 어긋난다. 실제 휘기를 아예 뺄지는 시대를 정할 때 함께 정한다.
- `src/sdk-host.js`의 `Object.hasOwn`은 사파리 15.4(2022) 이상에서 된다. 그보다 오래된 사파리는 지원하지 않는다.
