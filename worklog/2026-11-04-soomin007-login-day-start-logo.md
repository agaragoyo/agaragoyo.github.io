# 2026-11-04 로그인 화면의 밤 색과 2010 시작 단추 그림 (soomin007)

## 한 일
밤을 켠 채 로그인 화면으로 돌아오면 창이 어두워지고 1998에서는 사용자 이름이 거의 보이지 않던 것을 고쳤다.
2010의 둥근 시작 단추에서 집 그림이 왼쪽으로 치우치고 아래로 처져 보이던 것도 바로잡았다.

## 바꾼 파일
- `src/os.js`: 밤 테마를 정하는 일을 `syncTheme`으로 옮기고, 화면을 바꾸는 `show`에서 부름. 바탕화면이 보일 때만 밤 색을 쓴다
- `src/main.js`: 밤 테마를 정하던 줄을 뺌
- `style.css`: 2010 시작 단추의 `gap`을 0으로, 집 그림을 1.5px 올림
- `docs/guide.md`: 로그인 화면은 밤에도 낮 색이라는 설명
- `known-issues.md`: 38번(밤 설정이 로그인 화면까지 번진다), 39번(2010 시작 단추의 집 그림이 치우쳐 보였다)

## 정한 것과 이유
- 사용자 칸의 글자색만 고치는 대신 로그인 화면에서 밤을 쓰지 않기로 했다. 밤은 방의 불을 끈 상태이고 로그인 화면은 방에 들어가기 전이다. 튜토리얼이 스탠드를 켜고 끄게 하므로 누구나 만날 수 있는 상황이기도 하다.
- 밤 설정 값은 그대로 저장한다. 로그인하면 불을 꺼 둔 방으로 돌아간다.
- 집 그림은 viewBox 20 기준으로 감싸는 원의 중심이 y=11.625, 무게 중심이 y=11.2다. 22px로 그리면 상자 가운데보다 각각 1.8px, 1.3px 아래라서 그 사이인 1.5px을 올렸다.

## 남은 일과 알아 둘 것
- 2005의 시작 단추는 글자가 보이는 모양이라 고치지 않았다.
