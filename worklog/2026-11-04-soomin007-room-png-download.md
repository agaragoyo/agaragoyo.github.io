# 2026-11-04 공유하기에서 방 그림을 PNG로 내려받기 (soomin007)

## 한 일
공유하기 앱에 방 그림을 PNG 파일로 내려받는 단추를 더했다(F18). 내 방과 놀이터를 따로 내려받고, 누르는 순간의 방이 낮 모습 그대로
`agarago-room.png`, `agarago-playground.png`로 저장된다. 그림 크기는 2560×1440px로, 화면의 방(1280×720px)의 두 배다.
화면의 방은 SVG 바탕 위에 DOM 가구 상자를 CSS로 겹친 것이라 사진처럼 찍을 수 없어서, 화면과 같은 계산 함수를 불러다 캔버스에 다시 그린다.

## 바꾼 파일

- `src/apps/share-app.js`: 공간마다 "내 방 그림 PNG로 내려받기" 단추. 만드는 동안 "그림을 만드는 중"을 보여 주고, 실패하면 무슨 일이 있었고 무엇을 하면 되는지 알린다

- `src/room.js`: 가구에 쓸 그림 파일을 고르는 규칙을 `imageFor`로 꺼내 `furnitureEl`과 내려받기가 같이 씀(화면 동작은 그대로)
- `style.css`: 공유하기 창의 안내 글과 단추 줄 두 개
- `tools/check.py`: `check_room_image`. `style.css`의 `.room` 바탕 색이 `room-image.js`의 `BACKDROP`과 다르면 오류

## 정한 것과 이유
- 캔버스에 다시 그린다. DOM을 SVG `foreignObject`로 감싸 찍는 방법은 사파리에서 캔버스가 막히는 문제가 알려져 있어,
  html2canvas 같은 라이브러리는 CSS를 흉내 내는 것이라 기울인 벽 가구, 칠해진 모양 자르기, `color-mix`에서 어긋날 위험이 있어 시험하지 않고 뺐다.
- 바탕과 임시 모양(SVG)은 그림 한 장으로 바꿔 그린다. 그림 안에서는 페이지의 CSS 변수, 클래스, `color-mix`를 읽지 못해서,
  방과 같은 CSS를 받는 숨은 상자에 붙여 요소마다 최종 값을 읽어 적어 넣는다. 글자는 그림 안에서 웹폰트(Galmuri)를 쓸 수 없어 캔버스에 따로 쓴다.
  덕분에 2010에서는 화면처럼 맑은 고딕으로 나온다.
- 가구의 자리, 앞뒤 순서, 그림 고르는 규칙은 화면과 같은 함수(`placementOf`, `zOf`, `imageFor`)를 쓴다. 규칙을 따로 베껴 두면 한쪽만 고쳤을 때 어긋난다.
- 두 배 크기로 저장한다. 식탁 그림이 상자 크기의 두 배(288×283px)로 들어와 있어서, 1280×720px로 저장하면 그림이 흐려진다.
- 낮 모습만 저장하고 아바타는 넣지 않는다. 밤은 컴퓨터 전체의 설정이고 공유 링크에도 담기지 않으며, 아바타는 방 꾸미기 창에도 나오지 않는다.
  밤의 불빛(마스크와 번지는 그림자)까지 따라 그리려면 효과를 다시 만들어야 하고 화면과 맞는지 확인하기도 어려워 이번에는 뺐다.
- 공간마다 단추를 하나씩 둔다. 한 단추가 보고 있는 공간에 따라 다른 그림을 내려받으면 누르기 전에 결과를 알 수 없다(known-issues 32).
- 처음에는 그림을 `img.decode()`로 해독하게 했다. 탭이 가려진 동안 PNG의 `decode()`가 끝나지 않아 단추가 멈췄고, `onload`만 기다리게 바꿨다(known-issues 33).

## 확인한 것
- 2005, 2010, 1998에서 공유하기 창을 열어 단추를 눌렀다(1998은 볼록 화면이 넘기는 합성 클릭으로). 파일 이름, PNG 형식, 2560×1440px를 확인했다.
- 만든 그림을 방 꾸미기 창의 방 위에 `mix-blend-mode: difference`로 겹쳐 비교했다(2005는 내 방과 놀이터, 2010은 내 방). 가장자리의 부드러운 차이 말고는 검게 남았다.
  6배로 확대해 책상 위 물건과 이름표 글자, 놀이터 문 팻말의 기울기도 화면과 같은 것을 봤다. 내려받은 파일을 직접 열어서도 봤다.
- 낮과 밤에서 같은 파일이 나온다. 그림 만들기가 실패하는 두 경우(`toBlob`이 빈 값, 캔버스를 못 얻음)에서 안내가 뜨고 단추가 돌아오는 것도 확인했다.
- 걸리는 시간은 이 PC에서 그리기 0.1~0.2초, PNG 파일로 만들기 약 1.2초이고 파일은 1.7MB쯤이다(가구 17개의 시험 방).

## 남은 일과 알아 둘 것
- 사파리와 파이어폭스는 이 PC에서 띄울 수 없어 확인하지 못했다. 쓴 것은 캔버스 2D, `toBlob`, `XMLSerializer`, 크기를 적은 SVG 데이터 주소 그림, `getComputedStyle`, `document.fonts.load`다.
  맥 사파리로 단추를 눌러 파일이 나오고 화면과 같은지 확인을 받는다.
- 방 모양(바탕, 가구 상자, 그림 고르기)을 고치면 내려받은 그림도 같은 모양인지 본다. 바탕 색은 점검이 지켜 주고 나머지는 사람이 본다(known-issues 33).
- 공유 링크는 창을 처음 열 때의 방으로 만들어지고, 이미 열린 창은 다시 만들지 않는다. 창을 열어 둔 채 방을 고치면 링크가 이전 모습이 될 수 있다. 이번 일과 따로 다룬다. 그림은 누르는 순간의 방으로 만들어서 해당하지 않는다.
