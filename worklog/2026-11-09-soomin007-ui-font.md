# 2026-11-09 첫 화면 작은 글꼴 (soomin007)

## 한 일
느린 연결에서 첫 화면 가림막이 갈무리 글꼴 전체를 기다리느라 늦게 걷히던 것을 줄였다. 갈무리11에서 사이트가 화면에 쓰는 글자 437자만 남긴
작은 글꼴 AgaUI(보통과 굵게 합쳐 21KB)를 만들어, 첫 화면은 이 글꼴로 그리고 가림막도 이것만 기다린다.
사용자가 치는 닉네임과 말풍선처럼 작은 글꼴에 없는 글자는 가림막이 걷힌 뒤 이어 받는 갈무리 전체가 그린다.

## 바꾼 파일
- `tools/ui_font.py`: 작은 글꼴을 만드는 도구. `index.html`의 글, `style.css`의 `content`, `src`와 `data`의 자바스크립트 문자열(주석과 정규식은 빼고)에
  ASCII 전부와 한글 자모를 더한 글자만 jsdelivr의 갈무리11에서 남기고, 글꼴 안의 이름을 AgaUI로 바꾼다
- `assets/fonts/`: `aga-ui.woff2`(11.3KB), `aga-ui-bold.woff2`(10.1KB), 들어 있는 글자 목록 `aga-ui.txt`, 갈무리 라이선스 `OFL.txt`,
  이름을 바꾼 까닭과 다시 만드는 법을 적은 `README.md`
- `style.css`: 맨 위 "글꼴" 절에 AgaUI와 갈무리11 두 벌의 `@font-face`. `--font-base`를 AgaUI, Galmuri11 순서로 바꾸고 쓰이지 않던 Galmuri9를 뺐다
- `index.html`: jsdelivr의 `galmuri.css` 줄을 빼고, AgaUI 두 벌을 미리 받는 줄과 jsdelivr에 미리 연결하는 줄을 넣었다
- `src/main.js`: 가림막이 기다리는 `FIRST_FONTS`를 AgaUI로 바꾸고, 가림막을 걷은 뒤 `FULL_FONTS`(갈무리 전체)를 이어 받는다
- `tools/check.py`: `check_ui_font`. 작은 글꼴에 없는 사이트 글자는 경고하고, 글꼴 미리 받기 주소가 `style.css`와 다르거나 `crossorigin`이 없으면 오류로 알린다
- `known-issues.md`(42번 고침, 45번), `docs/file-map.md`, `docs/guide.md`, `docs/tasks.md`, `docs/checklists.md`

## 정한 것과 이유
- 고치기 전에 크롬에서 Fast 3G와 비슷한 연결(왕복 560ms, 초당 180KB)로 재 보니, 가림막은 글꼴 3초 상한에 걸려 4.91초에 걷히고 갈무리 보통 굵기는 6.19초에 왔다.
  글꼴 두 벌을 `preload`로 미리 받게 해도 가림막은 5.08초였고 main.js는 0.17초 늦어졌다. 658KB를 초당 180KB로 받는 데만 3.7초가 걸려서 받는 양을 줄여야 했다.
- 다른 곳의 방법을 먼저 찾아보았다. 구글 폰트와 Pretendard는 한국어 글꼴을 100여 조각으로 나누고 `unicode-range`로 필요한 조각만 받게 한다.
  갈무리11을 이렇게 나눈 공개본(fonts-archive, 굵기마다 120조각)으로 어림하니 우리 첫 화면에도 조각 10개와 조각 목록 CSS(gzip 46KB)까지 약 90KB가 들었다.
  첫 화면 글자만 담은 작은 글꼴을 먼저 받는 방법(Critical FOFT)은 두 벌 21KB로 끝나서 이것을 골랐다. 사이트 글자는 우리가 다 알고 있고 437자뿐이기 때문이다.
  한글 2,350자만 남기는 흔한 방법은 사용자가 아무 글자나 칠 수 있는 곳에 맞지 않아 버렸다.
- 작은 글꼴에는 첫 화면 글자만이 아니라 사이트가 쓰는 글자를 모두 넣었다. 첫 화면 글자만 넣을 때와 크기 차이가 10KB 남짓이고,
  부팅, 로그인, 바탕화면까지 기본 글꼴로 바뀌는 순간이 없어진다. 키보드로 치는 ASCII와 한글을 입력하는 동안 잠깐 보이는 자모(ㄱ~ㅣ)도 넣었다.
- 갈무리는 SIL OFL 1.1이고, `galmuri.css` 머리말에 "Galmuri"가 예약된 이름으로 적혀 있다. 라이선스 파일과 글꼴 안의 저작권 문구에는 이 말이 없지만
  저자가 낸 파일에 있으므로 따랐다. README와 저장소에도 서브셋을 따로 허락하는 글은 없었다. OFL은 글자를 덜어 낸 글꼴도 원본을 고친 판으로 보고
  예약된 이름을 쓰지 못하게 하므로, 글꼴 안의 이름(name 1, 3, 4, 6번)과 CSS 이름을 AgaUI로 바꾸고 원래 저작권과 라이선스 문구는 남겼다.
- 갈무리 전체는 jsdelivr에서 고치지 않은 원본을 받는다. 팀 앱(파일 정리 10, 짐 정리, 틀)이 부르는 `galmuri.css`와 주소가 같아 브라우저 캐시를 같이 쓴다.
  `galmuri.css`를 부르던 줄은 다른 도메인의 CSS가 화면 그리기와 main.js를 붙잡고 있어서 빼고, 쓰는 두 벌만 `style.css`에 적었다.
- 갈무리 전체는 가림막이 걷힌 직후부터 받는다. 처음 온 사람은 로그인 화면에서 닉네임을 치므로 그 전에 와 있게 하려는 것이다. 느린 연결에서는 6.3초쯤 도착한다.
- 고친 뒤 같은 조건에서 다섯 번씩 번갈아 잰 가운데 값은 아래와 같다(배포와 같은 HTTP/2 시험 서버). 연결 제한이 없을 때는 가림막이 걷히기 시작하는 때가 0.20초에서 0.08초로 당겨졌다.

  | 크롬, Fast 3G 정도 | 고치기 전 | 고친 뒤 |
  | --- | --- | --- |
  | main.js가 돎 | 1.91초 | 1.99초 |
  | 첫 화면 글꼴 도착 | 6.19초(갈무리 보통) | 1.92초(AgaUI 보통) |
  | 가림막이 걷히기 시작 | 4.91초 | 1.99초 |
  | 가림막이 빠짐 | 5.32초 | 2.41초 |
  | 가림막이 빠질 때까지 받은 양 | 268KB | 126KB |

- 재는 도구는 DevTools 방식이라 새 도메인에 연결하는 시간을 흉내 내지 않는다. 실제 3G에서는 jsdelivr의 CSS를 기다리던 몫(왕복 2~3번)도 줄었을 것으로 보지만 숫자로는 확인하지 못했다.

## 남은 일과 알아 둘 것
- 확인한 것: 크롬과 WebKit에서 세 시대 모두 처음 받는 글꼴이 AgaUI 두 벌이고, 갈무리 전체는 가림막이 걷힌 뒤에 받는다.
  AgaUI로 그린 모니터 아래 글자와 시대 스위치를 갈무리 전체로 그린 것과 비교하니 글자는 화소까지 같았다(크롬의 1998, 2005에서 소리 단추 모서리 한 화소만 밝기가 1 달랐다).
  로그인 화면에 작은 글꼴에 없는 "뷁똠"을 쳐도 갈무리로 보였고, 공유하기 PNG의 "아파트" 표지판도 그대로 그려졌다.
  가림막 점검은 크롬 29/29, WebKit은 고치기 전과 같은 종류로 23/29다(이 WebKit이 원래 1.4초쯤 걸린다). 파이어폭스는 확인하지 못했다.
- 화면에 새 글자를 넣으면 `tools/check.py`가 경고한다. 그때 `pip install fonttools brotli` 뒤 `python tools/ui_font.py`를 돌린다.
  다시 만들지 않아도 그 글자만 갈무리 전체가 올 때까지 기본 글꼴로 보일 뿐 깨지지는 않는다.
- 갈무리 버전을 올리면 `style.css`의 두 주소와 팀 앱의 `galmuri.css` 주소를 같이 올리고 `tools/ui_font.py`를 다시 돌린다. 주소가 다르면 캐시를 같이 쓰지 못한다.
- 합쳐서 배포한 뒤 같은 방법으로 배포 주소를 다시 잰다.
- 재는 데 쓴 스크립트는 레포 밖 `%LOCALAPPDATA%\agarago-webkit-check\scripts`의 `font-timing.mjs`(시간), `font-flow.mjs`(글꼴 순서와 화소 비교),
  `png-diff.mjs`이고 그 폴더의 README에 적어 두었다.
