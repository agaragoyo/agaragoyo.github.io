# 2026-11-10 옛날 컴퓨터에 좋아하는 웹 게임 넣기 (soomin007)

## 한 일
Admin이 12주차까지 맡은 가구 인터랙션 다섯 개(게임기, 라디오, 옛날 컴퓨터, TV, 책장) 가운데 첫 번째로 옛날 컴퓨터를 만들었다.
바탕화면에서 컴퓨터를 두 번 누르면 이제 미니게임 폴더 대신 주인이 넣어 둔 웹 게임이 어느 사이트의 새 탭에서 열리는지 알려 주고, "새 탭에서 열기"로 연다.
주인이 가구마다 담아 두는 것(F12)을 집 상태와 공유 링크에 싣는 공통 부분도 같이 만들어, 나머지 네 가구가 같은 길을 쓰게 했다.

## 바꾼 파일
- `src/likes.js`: 새 파일. 집 상태의 `likes`(가구 id마다 한 칸), 저장본과 링크에서 온 값 검사, 주소 검사(`safeLink`), 바꾸고 저장하기(`setLike`)
- `src/share.js`: 집 상태와 공유 링크에 `likes`(링크에서는 `l`)를 더함. `l`이 없는 예전 링크도 그대로 열린다
- `src/apps/computer-app.js`: 새 파일. 새 탭 안내 창, 주인에게만 보이는 넣기, 고치기, 게임 빼기 칸
- `src/apps/link-app.js`: 새 탭 안내와 단추를 `linkPrompt`로 떼어 컴퓨터와 같이 씀
- `src/os.js`: 아바타 한마디(`os.say`), 가구에 넣은 것만 바뀌면 방을 다시 그리지 않고 저장만 하기(`os.saveHome(false)`)
- `data/apps.js`, `src/apps/index.js`, `data/furniture.js`: 컴퓨터 앱(`folder: 'furniture'`)을 더하고 컴퓨터 가구의 기믹을 `app:computer`로 바꿈
- `style.css`: 넣는 칸과 오류 줄, 밤의 오류 글자색
- `assets/fonts/aga-ui*.woff2`, `assets/fonts/aga-ui.txt`: 새 문구의 글자를 작은 글꼴에 넣음(`python tools/ui_font.py`)
- `AGENTS.md`, `docs/requirements.md`, `docs/tasks.md`, `docs/guide.md`, `docs/file-map.md`: 주인이 가구에 담아 두는 것을 붙이는 곳, F7과 F12 상태, 정한 것

## 정한 것과 이유
- 주인이 넣는 곳은 사용자와 정해 가구 화면으로 했다. 내 컴퓨터에서 가구를 두 번 누르면 넣는 칸이 뜨고, 손님에게는 없다. 요구 사항의 "책장을 누르면 책을 정합니다"와 같은 방식이라 다섯 가구가 모두 따른다.
- 넣은 것은 가구 종류마다 한 칸이다. 같은 가구를 둘 놓아도 같은 게임이 뜬다. 피그마 표가 "가구마다 좋아하는 것"이라 놓인 자리마다 따로 두지 않았다.
- 손님 화면에도 뜨는 글이라 `h()`의 자식(글자)으로만 넣고, 링크는 http와 https만 받는다. 시험에서 `javascript:` 주소를 넣은 링크는 버려지고, 이름에 넣은 `<img onerror>`는 글자로만 보였다.
  주인이 넣은 링크는 우리 주소를 알릴 까닭이 없어 `rel="noopener noreferrer"`로 연다. 미니게임 폴더의 플래시 게임은 예전대로 `noopener`만 둔다.
- 주소창에서 `https://`를 빼고 옮겨 적는 일이 많아서, 앞에 붙은 것이 없으면 `https://`로 본다.
- 손님이 아무것도 넣지 않은 컴퓨터를 쓰면 빈 창 대신 아바타가 "넣어 둔 게임이 없네."라고 한다. 기믹이 없는 가구에서 이름을 말하는 것과 같은 자리라 창을 띄우지 않았다.
- 공유 링크가 너무 길어지지 않게 가구마다 글자 수를 줄였다(주소 300자, 게임 이름 20자).

## 남은 일과 알아 둘 것
- 확인: `python tools/check.py` 오류 0개. 화면 없는 크롬에서 진짜 마우스 입력으로 18가지를 눌러 봤다(빈 컴퓨터의 넣는 칸, 잘못된 주소의 오류, 넣기와 저장, 새 탭 안내 문장과 주소, 고치기와 취소, 새 탭이 실제로 열리고 창이 닫힘, 공유 링크로 들어온 손님 화면, 위험한 링크, 밤의 글자 대비).
- 미니게임 폴더는 이제 바탕화면 아이콘으로만 연다. 게임기 가구가 게임 목록을 여는 것은 다음 PR에서 한다.
- iframe으로 만든 팀원 앱은 아직 `likes`를 읽지 못한다. 주인이 내용을 넣는 가구는 지금은 OS 기본 앱으로 만들어야 하고, 앱에서도 읽어야 하면 SDK에 기능을 더한다.
