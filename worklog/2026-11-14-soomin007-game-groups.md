# 2026-11-14 게임 폴더를 세 묶음으로 나누고 말랑이 디저트가게 넣기 (soomin007)

## 한 일
알파 테스트에서 "미니게임이 미니게임 같지 않다"는 말이 있었다. 폴더의 게임 16개 가운데 우리가 만든 것은 둘뿐이고,
나머지는 다른 사이트의 큰 게임 다섯 개와 새 탭으로 여는 플래시 게임과 영상 아홉 개인데 한 줄에 섞여 있었다.
앱 줄에 `group` 칸을 더해 "미니게임", "설치한 게임", "추억의 플래시 게임" 세 묶음으로 나누고,
바탕화면 폴더 창과 게임기 화면이 같은 이름과 순서로 보여 주게 했다. 바탕화면 아이콘과 창 제목은 "게임"으로 바꿨다.
같은 수업 다른 조가 요청한 말랑이 디저트가게도 "설치한 게임"에 넣었다. 게임은 하나도 빼지 않았다.

## 바꾼 파일
- `data/apps.js`: `group` 칸과 `GAME_GROUPS`, `groupGames()`, `hostTip()`. 말랑이 한 줄. 폴더 아이콘 이름 "게임"
- `src/apps/folder-app.js`: 묶음 제목 아래에 아이콘을 늘어놓고 창 높이에 제목 줄(30px)을 더함
- `src/apps/console-app.js`: 게임기 첫 화면을 같은 묶음으로 나눔. 위아래 이동은 화면 위치로 옮기고, 추천 게임은 자기 묶음의 맨 앞에 서며 처음 초점이 간다
- `src/os.js`: 아이콘 툴팁을 `hostTip()`으로. 폴더 안 선택 표시는 묶음이 달라도 하나만 남게
- `style.css`: `.folder-group`, `.folder-icons`, `.console-group`, `.console-tiles`
- `tools/check.py`: 게임 폴더 앱에 `group` 필수, 그 밖의 앱에는 쓰지 않음
- `assets/fonts/aga-ui*.woff2`, `aga-ui.txt`: 새 글자(랑, 설, 억)를 작은 글꼴에 더함
- `docs/requirements.md`(F9, F16, 정한 것), `docs/tasks.md`, `docs/guide.md`, `docs/file-map.md`, `docs/checklists.md`, `apps/README.md`

## 정한 것과 이유
- 묶음을 적는 칸 이름은 `group`. 묶음 이름과 순서는 한 곳(`GAME_GROUPS`)에 두어 폴더와 게임기가 어긋나지 않게 했다.
  `{ id: ... }` 모양으로 적으면 `tools/check.py`가 앱 줄로 읽어서 `group:`을 앞에 두었다.
- 게임기의 추천 게임은 그대로 고를 수 있다(이미 보낸 공유 링크의 `likes.console`이 깨지지 않게). 추천 게임은 전체 맨 앞이 아니라 자기 묶음의 맨 앞에 선다.
- 말랑이는 파일을 옮기지 않고 `src: 'https://playmallangi.com/'`로 띄운다. 창 크기는 440×640으로 두었다.
  실제 OS 창에서 선택 화면, 게임 시작, 한 판(떨어뜨려 합치기, 합쳐서 +$100)까지 눌러 보았다. 처음에는 일일 퀘스트 팝업이 먼저 뜬다.
- 다른 사이트의 게임을 창에 띄우는 아이콘은 마우스를 올리면 "창에서 열립니다(주소)"가 뜬다. 새 탭 아이콘의 "새 탭에서 열립니다(주소)"와 같은 방식이다.

## 남은 일과 알아 둘 것
- 게임 폴더에서 뺄 게임과 넣을 게임은 팀이 정한다(`docs/tasks.md`).
- 게임 폴더는 묶음 제목 때문에 최대 높이(640px)에서도 아이콘 칸을 스크롤해야 한다. 게임이 더 늘면 폴더 창 폭을 넓히는 것을 생각해 본다.
