# 2026-11-17 실험실 세 항목을 모든 사람에게 켜기 (soomin007)

## 한 일

실험실(F24)에 있던 주인 아바타 남기기, 담긴 가구 반짝임, 펫 데려오기를 Admin이 정해 모든 사람에게 켰다.
이제 친구 집에 가면 주인 아바타가 방에 서 있고(F8), 담아 둔 가구 위에 별이 뜨며(F12), 내 방에는 펫이 산다(새 번호 F30).
펫은 실험실 창의 펫 바꾸기 단추 대신 시작 메뉴의 "펫 바꾸기"에서 고르고, 종류 줄 끝의 "없음"을 고르면 펫을 두지 않는다.

## 바꾼 파일

- `src/labs.js`, `src/apps/labs-app.js`: 세 항목과 펫 바꾸기 단추를 뺐다. 실험실에는 화면 보호기 빨리 보기, 친구 집 배경음악, 심심할 때 혼잣말이 남는다
- `src/os.js`: 주인 아바타, 반짝임, 펫이 실험실 확인 없이 돈다. 시작 메뉴의 튜토리얼 다시 보기와 이름 바꾸기 사이에 펫 바꾸기 줄을 더했다
- `src/pet-picker.js`, `src/pet.js`, `src/settings.js`: 펫 바꾸기 창과 "없음"(`NO_PET`, 설정값 `none`)
- `src/icons.js`: 시작 메뉴와 창 제목에 쓰는 회색 고양이 얼굴 아이콘(`pet`, 24칸)
- `style.css`: 실험실 창의 펫 바꾸기 단추 규칙을 지우고, "없음"의 점선 네모와 숨긴 색 묶음(`[hidden]` 짝) 규칙을 더했다
- `src/avatar.js`, `src/horror.js`, `data/avatars.js`, `data/pets.js`: 실험실을 가리키던 주석
- `tools/smoke.mjs`, `tools/night-contrast.mjs`: 실험실 스위치를 켜던 확인을 기본 동작과 시작 메뉴로 여는 확인으로 바꿨다
- `docs/requirements.md`, `docs/guide.md`, `docs/file-map.md`, `docs/tasks.md`

## 정한 것과 이유

- 펫을 고르는 입구는 시작 메뉴의 글자 줄로 두었다. 펫이 바뀌는 곳은 방이라 다른 입구가 보이지 않고,
  이름 바꾸기를 이름에만 달았을 때 아무도 찾지 못한 일이 있었다(known-issues 80).
- 모두에게 켜더라도 방에 펫이 돌아다니는 것을 싫어할 사람이 있을 수 있어서 "없음"을 두었다. 고르기 전에는 지금처럼 회색 고양이가 산다.
- 반짝임은 주인 화면과 손님 화면 모두에 그대로 띄운다. 주인이 손님과 같은 방을 보게 하려는 것이다.
- 펫은 여전히 이 브라우저에만 남고 공유 링크에는 담지 않는다. 손님에게 보이게 하려면 집 저장 형식을 바꿔야 해서 따로 정한다.
- 눌러 보기 점검은 펫 절 전까지 펫을 "없음"으로 둔다. 펫이 무작위 빈칸에 앉으면 아바타가 걷는 길이 바뀌어 다른 절의 확인이 흔들릴 수 있다.
  펫 절은 설정을 비워 고르기 전 모습부터 보고, "없음"과 다시 고르기, 친구 집의 시작 메뉴에 펫 바꾸기가 없는 것까지 본다.

## 남은 일과 알아 둘 것

- 펫에 어떤 종류를 남기거나 더할지, 손님에게도 보일지, 물과 밥을 줄지는 요구 사항의 "아직 정하지 않은 것"에 남겼다.
- 처음 온 사람의 튜토리얼에도 기본 펫이 같이 나온다. 튜토리얼 다시 보기의 연습 방에는 나오지 않는다.
- 안내서의 실험실 항목 수가 놀이터를 뺀 뒤에도 "일곱 가지"로 남아 있어서 "세 가지"로 고쳤다.
- 확인: `python tools/check.py` 오류 0개, `node tools/night-contrast.mjs` 실패 0개, `node tools/smoke.mjs` 실패 0개.
  미리보기에서 새 사용자를 만들면 회색 고양이가 나오고, 시작 메뉴의 펫 바꾸기로 "없음"을 고르면 사라지며 새로 고침해도 그대로인 것을 봤다.
