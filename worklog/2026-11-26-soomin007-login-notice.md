# 2026-11-26 새 기능 안내와 이 컴퓨터에서 지우기 (soomin007)

## 한 일
아이디와 비밀번호 로그인(F36)을 합친 뒤의 후속이다. 아이디와 비밀번호가 생기기 전부터 있던 사용자에게 내 컴퓨터로 들어올 때 "새 기능 안내" 창을 한 번 띄운다.
로그인 화면의 "이 컴퓨터에서 빼기"와 "빼고 로그인"은 어색하다는 지적이 있어 "이 컴퓨터에서 지우기"와 "지우고 로그인"으로 바꿨다.
관리자가 자기 사용자 둘로 실제 서버에서 비밀번호 만들기와 다른 브라우저 로그인을 해 보았고 둘 다 되었다.

## 정한 것과 이유
- 낱말은 같은 자리의 실제 문구를 모아 골랐다. 구글은 로그인 화면의 계정 목록에서 "계정 삭제", 네이버 지도는 로그아웃할 때 "간편로그인 삭제", 스팀은 "계정 로그아웃"을 쓴다.
  "로그아웃"이 가장 흔하지만 이 사이트에서는 시작 메뉴의 로그아웃이 로그인 화면으로 돌아가는 뜻이라 둘이 겹친다. 그래서 "이 컴퓨터에서 지우기"로 쓰고 서버의 방이 남는다는 것은 확인 줄에 둔다.
  다른 아이디로 로그인할 때의 단추도 비밀번호가 있든 없든 "지우고 로그인" 하나가 되었고, 되돌릴 수 있는지는 확인 줄이 가른다.
- 안내는 비밀번호가 없고 본 표시가 없는 사용자에게만 띄운다. 새 사용자는 튜토리얼 끝 카드가 같은 것을 알리므로 만들 때 본 것으로 두고,
  비밀번호가 있거나 로그인이 풀린 사용자(다시 로그인하는 창이 뜬다)에게는 띄우지 않는다. 창을 어떻게 닫든 본 것으로 둔다.
- 안내의 셋째 줄은 같이 쓰는 컴퓨터에서 다 쓴 뒤 로그아웃하고 이 컴퓨터에서 지우기를 누르라는 것이다. 시작 메뉴의 로그아웃만으로는 사용자가 로그인 화면에 남아
  다음 사람이 비밀번호 없이 들어간다. 학교 컴퓨터에서 로그인하는 사람이 가장 모르기 쉬운 것이라 넣었다.
- 메뉴와 단추 이름은 윈도우 XP 도움말처럼 굵게 썼다. 이 사이트의 다른 문구는 이름을 따옴표 없이 쓰는데, 안내 창에는 이름이 넷이나 들어가 어디까지가 이름인지 헷갈렸다.
  처음 찍은 화면에서 셋째 줄이 "이 / 컴퓨터에서 지우기"로 이름 가운데서 꺾여, 이름과 조사를 한 묶음(`white-space: nowrap`)으로 감쌌다.

- 실제 서버에서 아직 보지 못한 것은 양쪽에서 고치기, 비밀번호 바꾸기, 이 컴퓨터에서 지우기, 판 조건이 거절되는 모양, `WEAK_PASSWORD`와 `EMAIL_EXISTS`의 모양이다(`docs/tasks.md`).
- 한 브라우저에는 지금도 사용자가 한 명만 앉는다. 사용자의 것을 담는 저장소 키가 한 사람 몫이라, 다른 아이디를 쓰려면 지우고 로그인한다. 여럿을 두려면 따로 설계가 필요하다.
